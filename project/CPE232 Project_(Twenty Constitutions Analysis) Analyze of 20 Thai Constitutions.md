#  **Introduction**

ประเทศไทยมีรัฐธรรมนูญรวมทั้งสิ้น 20 ฉบับ นับตั้งแต่ปี พ.ศ. 2475 จนถึงปัจจุบัน ซึ่งถือว่าเยอะมากที่สุดเมื่อเทียบกับประเทศที่ปกครองในระบอบประชาธิปไตย รัฐธรรมนูญแต่ละฉบับสะท้อนบริบทการเมืองที่แตกต่างกัน ไม่ว่าจะรัฐบาลพลเรือน คณะรัฐประหาร หรือสภาเฉพาะกาล ดังนั้นโครงงานนี้มีเป้าหมายในการรวบรวม ดิจิทัลไลซ์ และวิเคราะห์รัฐธรรมนูญทั้ง 20 ฉบับในฐานะคลังข้อความ (Text Corpus) โดยใช้เทคนิค OCR, NLP, และ ML เพื่อตอบคำถามหลักว่า “รัฐธรรมนูญไทยเปลี่ยนแปลงอย่างไรตลอด  9 ทศวรรษ และการเปลี่ยนนี้สะท้อนประวัติศาสตร์การเมืองไทยอย่างไร?” นอกจากนี้ยังนำข้อมูล Structured จาก [Constituteproject.org](http://Constituteproject.org) ซึ่งจัดทำดัชนีสิทธิ์ตามรัฐธรรมนูญของแต่ละประเทศ มาใช้เปรียบเทียบการคุ้มครองสิทธิในรัฐธรรมนูญไทยแต่ละฉบับเชิงปริมาณ

# **Objectives**

- สร้างคลังข้อความ (Corpus) ของรัฐธรรมนูญ 20 ฉบับ โดยใช้ OCR, และการดึงข้อมูลจากไฟล์ pdf  
- วิเคราะห์โครงสร้าง ได้แก่ จำนวนมาตรา ความยาว การแบ่งหมวด และความถี่ในการแก้ไขเพิ่มเติม  
- หาการเปลี่ยนแปลงเชิงหัวข้อและภาษา ระหว่างแต่ละยุคการเมือง  
- วัดและเปรียบเทียบสิทธิในรัฐธรรมนูญแต่ละฉบับ จากดัชนีของ [constituteproject.org](http://constituteproject.org)  
- วัดความคล้ายคลึงระหว่างรัฐธรรมนูญแต่ละฉบับ   
- สร้างโมเดล Machine Learning เพื่อวิเคราะห์โครงสร้าง โดยประยุกต์ใช้ความรู้จากวิชา CPE 232 Data Models ในทุกขั้นตอนที่สอดคล้องกับเนื้อหารายวิชา

# **Methodologies**

1. ## **Data Preparation**: เนื่องจากรัฐธรรมนูญไทยมีรูปแบบที่แตกต่างกันตามยุคสมัย จึงแบ่งวิธีเตรียมชุดข้อมูลออกเป็น 2 แบบ ได้แก่ รัฐธรรมนูญในรูปแบบรูปภาพในช่วง พ.ศ. 2475–2502 ซึ่งดำเนินการผ่าน Optical Character Recognition (OCR) ด้วย **Typhoon OCR 1.5** ที่รองรับภาษาไทยโดยเฉพาะ และดึงข้อความ  (text extraction) จากรัฐธรรมนูญในรูปแบบ PDF ในช่วง พ.ศ. 2511–2560 ออกมาโดยทั้งสองแบบจะผ่านการตรวจสอบความถูกต้องของข้อความภายหลัง

2. ## **Exploratory Data Analysis (EDA):** การวิเคราะห์ขั้นตอนนี้ช่วยให้สามารถตรวจสอบคุณภาพของข้อมูลจาก OCR และ text extraction รวมถึงช่วยในการออกแบบขั้นตอนการประมวลผลข้อมูลและการสร้างแบบจำลอง Machine Learning 

   1. ### **Dataset Overview:** ทำการสำรวจข้อมูลภาพรวมของชุดข้อมูล เช่น ความยาวของข้อความ จำนวนรัฐธรรมนูญทั้งหมดในชุดข้อมูล ช่วงปีของรัฐธรรมนูญที่ศึกษา จำนวนหมวด (chapters) และมาตรา (articles) ในแต่ละฉบับ

   2. ### **Text Analysis เช่น** จำนวนคำทั้งหมดในรัฐธรรมนูญแต่ละฉบับ, จำนวนคำเฉลี่ยต่อมาตรา, การกระจายตัวของความยาวข้อความในแต่ละมาตรา, คำที่เกี่ยวข้องหรือ Keywords ต่าง ๆ

3. ## **Data Cleaning and Data Preprocessing**

   1. ### **Normalization** Normalize Unicode ภาษาไทย และลบ Header/Footer ที่ไม่เกี่ยวข้องออก, แบ่งข้อความเป็นหน่วยโครงสร้าง: หมวด / มาตรา / วรรค และ Standardize ฟิลด์ Metadata เช่น วันที่ ตัวเลขมาตรา และป้ายชื่อยุคการเมือง

   2. ### **Tokenization ภาษาไทย:** โดยใช้เครื่องมือสำหรับการตัดคำภาษาไทย เช่น PyThaiNLP Attacut เพื่อแบ่งข้อความออกเป็นคำ (tokens) ที่สามารถนำไปใช้การวิเคราะห์ต่อไปได้

   3. ### **Text Cleaning เช่น** ลบคำที่ไม่ให้ข้อมูลเชิงความหมายสำคัญ (Stopword Removal) เช่น คำเชื่อม หรือคำทั่วไปในภาษาไทย, แปลงเลขไทยให้เป็นเลขอารบิกและ ลบสัญลักษณ์ที่ไม่ได้เกี่ยวข้องกับเนื้อหา

4. ## **Feature Extraction**

   1. เพื่อให้แบบจำลอง Machine Learning และการ Visualization สามารถประมวลผลข้อมูลข้อความได้ จำเป็นต้องแปลงข้อความให้อยู่ในรูปแบบเชิงตัวเลข

      1. ### **Bag-of-Words (BoW)** เพื่อแสดงความถี่ของคำในเอกสาร

      2. ### **TF–IDF (Term Frequency–Inverse Document Frequency)** เพื่อสะท้อนความสำคัญของคำในแต่ละรัฐธรรมนูญ

      3. ### **Word Embeddings** เพื่อแทนความหมายของคำในรูปแบบเวกเตอร์ โดยใช้ Language Model ภาษาไทย เช่น WangChanBERTa

5. ## **Data Visualization**

   1. เน้นกราฟที่สามารถแสดงแนวโน้มและการเปรียบเทียบข้อมูลระหว่างรัฐธรรมนูญแต่ละฉบับ เช่น

      1. ### **Timeline of Constitutions:** สร้าง timeline แสดงลำดับเวลาของรัฐธรรมนูญไทย เพื่อให้เห็นภาพรวมของการเปลี่ยนแปลงทางการเมืองในแต่ละช่วงเวลา โดยกราฟจะแสดงปีที่รัฐธรรมนูญเริ่มใช้และปีที่สิ้นสุดการใช้งาน

      2. ### **Rights Distribution Across Constitutions:** ผลลัพธ์จะแสดงในรูปแบบ heatmap ซึ่งแกนหนึ่งเป็นประเภทของสิทธิ และอีกแกนหนึ่งเป็นปีของรัฐธรรมนูญ

      3. ### **Amendment Frequency**: สร้างกราฟแสดง **จำนวนครั้งของการแก้ไขรัฐธรรมนูญ (amendments)** ในแต่ละฉบับ เพื่อวิเคราะห์ความเสถียรของรัฐธรรมนูญในแต่ละยุค

      4. ### **Topic Distribution in Constitutions:** ใช้ผลลัพธ์จากการวิเคราะห์ **topic modeling** เพื่อแสดงหัวข้อสำคัญในรัฐธรรมนูญแต่ละฉบับ

      5. ### **Constitution Similarity Matrix**: เพื่อวิเคราะห์ความคล้ายคลึงกันของรัฐธรรมนูญแต่ละฉบับ จะมีการคำนวณ **document similarity** จากข้อความของรัฐธรรมนูญ

6. ## **Machine Learning Modeling** 

   1. ### **Topic Modeling:** ใช้เทคนิคการเรียนรู้แบบไม่ต้องมีป้ายกำกับ (unsupervised learning) เพื่อค้นหารูปแบบหัวข้อสำคัญในรัฐธรรมนูญแต่ละฉบับ และทำการ Benchmark โดยวิธีการ เช่น  Topic coherence,  Topic Diversity
