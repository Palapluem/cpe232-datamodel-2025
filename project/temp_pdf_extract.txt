1.1 
ที่มาและความส าคัญ 
รถยนต์เป็นหนึ่งในรูปแบบกำรเดินทำงที่ส ำคัญทั่วโลกมำเป็นเวลำหลำยทศวรรษ โดยตลำดรถยนต์มือสอง
เป็นหนึ่งในตลำดที่ส ำคัญของอุตสำหกรรมยำนยนต์ อย่ำงไรก็ตำม ตลำดรถยนต์มือสองยังคงประสบปัญหำกำรตั้ง
รำคำขำยที่สูงเกินจริง 
โดยเฉพำะในกรณีที่ผู้ขำยบำงรำยฉวยโอกำสจำกควำมรู้ที่จ ำกัดของผู้ซื้อเกี่ยวกับรำคำซื้อ
ขำยของรถยนต์มือสองมำเป็นช่องโหว่ในกำรหำก ำไร ซึ่งกำรตั้งรำคำที่สูงเกินจริงของผู้ขำยอำจเกิดจำกควำมตั้งใจ 
หรือกำรขำดควำมโปร่งใส ซึ่งอำจท ำให้ผู้ซื้อสูญเสียเงินมำกกว่ำที่ควรจะเป็น และลดควำมเชื่อมั่นของตลำดรถมือ
สองลงอย่ำงมำก 
เรำจึงได้เลือกสร้ำงแบบจ ำลองส ำหรับกำรคำดกำรณ์รำคำรถยนต์มือสองเพื่อช่วยสร้ำงควำมตระหนักรู้
ให้กับลูกค้ำและป้องกันไม่ให้ถูกตั้งรำคำขำยที่สูงเกินควำมเป็นจริงจำกเต็นท์รถหรือผู้ขำยรำยบุคคล 
ด้วยกำร
วิเครำะห์จำกปัจจัยต่ำง ๆ เช่น รำคำ ระยะทำงกำรใช้งำน (odometer) สภำพรถ ยี่ห้อ รุ่น ปีที่ผลิต และประเภท
เชื้อเพลิง เป็นต้น โดยผู้จัดท ำตั้งเป้ำที่จะให้ผลกำรประเมินรำคำที่แม่นย ำจำกข้อมูลที่เป็นกลำง เพื่อส่งเสริมให้
ผู้บริโภคสำมำรถตัดสินใจได้โดยมีข้อมูลประกอบ และช่วยส่งเสริมให้เกิดกำรซื้อขำยที่เป็นธรรมและโปร่งใสในตลำด
รถยนต์มือสอง 
1.2 
วัตถุประสงค์ 
1. เพื่อพัฒนำแบบจ ำลองส ำหรับคำดกำรณ์รำคำรถยนต์มือสอง โดยใช้เทคนิคกำรเรียนรู้ของเครื่อง 
(Machine Learning) 
2. เพื่อให้ผู้ใช้งำนสำมำรถเข้ำถึงรำคำประเมินรถยนต์มือสองที่ตนสนใจ เพื่อใช้เป็นข้อมูล
ประกอบกำรตัดสินใจ และลดโอกำสในกำรถูกตั้งรำคำขำยที่เกินจริง 
3. เพื่อทดลองและเปรียบเทียบประสิทธิภำพของโมเดลกำรเรียนรู้ โดยประเมินจำกตัวชี้วัดทำงสถิติ 
เช่น ค่ำ MAE, RMSE และ R² เพื่อหำโมเดลที่เหมำะสมที่สุดส ำหรับกำรคำดกำรณ์รำคำรถยนต์
มือสองในบริบทของข้อมูลจริง

1.4 
เครื่องมือที่ใช้ในการพัฒนา 
โครงงำนนี้ได้ใช้เครื่องมือและไลบรำรีต่ำง ๆ ดังนี้: 
1. Pandas: ไลบรำรีส ำหรับกำรจัดกำรและวิเครำะห์ข้อมูลในรูปแบบตำรำง (DataFrame) ใช้งำนง่ำย
และทรงพลังในกำรจัดกำรข้อมูลที่มีโครงสร้ำง เช่นไฟล์ CSV หรือ SQL table 
2. Numpy: ไลบรำรีส ำหรับกำรค ำนวณเชิงตัวเลขที่มีประสิทธิภำพสูง โดยเฉพำะกับอำร์เรย์หลำยมิติ 
(ndarray) และฟังก์ชันคณิตศำสตร์ต่ำงๆ 
3. Matplotlib: ไลบรำรีส ำหรับสร้ำงกรำฟและแผนภูมิทำงสถิติ  
4. Scikit-learn: ไลบรำรี Machine Learning ที่ครอบคลุมกำรเรียนรู้ของเครื่องทั้ง Supervised และ 
Unsupervised เช่น กำรจัดกลุ่ม กำรถดถอย กำรจ ำแนก 
5. Warnings: ไลบรำรีมำตรฐำนของ Python ส ำหรับแสดงค ำเตือน (warning) แทนกำรหยุดโปรแกรม
ทันที ช่วยให้นักพัฒนำทรำบปัญหำที่อำจเกิดขึ้น 
6. fuzzywuzzy: ไลบรำรีส ำหรับกำรจับคู่อักษรแบบไม่เป๊ะ (fuzzy matching) เช่น กำรเปรียบเทียบค ำ
ที่พิมพ์ผิดหรือไม่ตรงกัน 100% โดยใช้ Levenshtein Distance 
7. tqdm: ไลบรำรีส ำหรับแสดงแถบ Progress bar ใช้งำนง่ำยและมีประโยชน์มำกในกำรติดตำม
ควำมเร็วกำรประมวลผล 
8. seaborn: ไลบรำรีย่อยของ Matplotlib ที่ออกแบบมำเพื่อกำรสร้ำงกรำฟสถิติที่ดูดีและใช้งำนง่ำย 
เช่น heatmap, distribution plot 
9. joblib: ไลบรำรีส ำหรับกำรจัดเก็บและโหลดอ็อบเจกต์ Python เช่น โมเดล Machine Learning ที่
ฝึกไว้แล้ว 
10. Kneed: ไลบรำรีส ำหรับท ำ Elbow Method หำจ ำนวนคลัสเตอร์ที่เหมำะสมใน K-Means 
11. scipy.stats: โมดูลย่อยของ SciPy ส ำหรับกำรค ำนวณทำงสถิติ เช่น ค่ำสหสัมพันธ์ กำรแจกแจง 
ควำมน่ำจะเป็น และกำรทดสอบสมมุติฐำน 
12. mpl_toolkits: กำรแสดงผล 3 มิติ 
13. xgboost: ไลบรำรีส ำหรับกำรเรียนรู้ของเครื่องแบบ Gradient Boosting ที่มีประสิทธิภำพสูง 
14. optuna: ไลบรำรีส ำหรับกำรท ำ hyperparameter tuning อย่ำงมีประสิทธิภำพ โดยใช้แนวคิดของ 
optimization เพื่อค้นหำค่ำที่ดีที่สุดของโมเดล

ผู้จัดท ำได้ท ำกำรส ำรวจและวิเครำะห์ข้อมูลจำกชุดข้อมูลชื่อ Used Cars Dataset ซึ่งเป็นชุดข้อมูลจำก 
Craigslist ซึ่งเป็นแหล่งรวมประกำศขำยรถยนต์มือสองที่ใหญ่ที่สุดในโลก โดยมีจุดประสงค์เพื่อท ำควำมเข้ำใจ
ลักษณะของข้อมูลก่อนกำรน ำไปประมวลผลและฝึกโมเดล โดยมีรำยละเอียดดังนี้ 
2.1 
ค าอธิบายข้อมูล 
 
Craigslist เป็นแหล่งรวมประกำศขำยรถยนต์มือสองที่ใหญ่ที่สุดในโลก อย่ำงไรก็ตำม กำรรวบรวมข้อมูล
รถยนต์ทั้งหมดให้อยู่ในที่เดียวกันนั้นเป็นเรื่องที่ยำก ผู้จัดท ำข้อมูลนี้ได้สร้ำงตัวดึงข้อมูล (scraper) ส ำหรับโครงงำน
ในโรงเรียน และได้ขยำยผลงำนนี้ต่อมำเพื่อสร้ำงชุดข้อมูลนี้ ซึ่งประกอบด้วยรำยกำรรถยนต์มือสองทั้งหมดใน
สหรัฐอเมริกำที่อยู่บน Craigslist ท ำให้ข้อมูลชุดนี้ถูกดึงใหม่ในทุก ๆ ไม่กี่เดือน โดยประกอบด้วยข้อมูลส ำคัญที่ 
Craigslist ให้ไว้เกี่ยวกับกำรขำยรถยนต์ เช่น รำคำ สภำพรถ ผู้ผลิต พิกัดละติจูด/ลองจิจูด และหมวดหมู่อื่น ๆ อีก 
18 หมวดหมู่ โดยส ำหรับโปรเจกต์ด้ำนกำรเรียนรู้ของเครื่อง (ML) แนะน ำให้ท ำกำรแปลงฟีเจอร์จำกข้อมูลต ำแหน่ง 
เช่น ค่ำละติจูด/ลองจิจูด และหำกต้องกำรข้อมูลจำกรำยกำรเก่ำ สำมำรถตรวจสอบจำกเวอร์ชันก่อนหน้ำของชุด
ข้อมูลได้

2.4 
คุณภาพของข้อมูล 
 
จำกข้อมูลพบว่ำมีปัญหำที่ต้องได้รับกำรแก้ไขก่อนน ำไปใช้ ดังนี้ 
• Missing value: มีข้อมูลข้อมูลขำดหำย 
• Out of date data (ex. url): มีข้อมูลที่ล้ำสมัย เช่น url 
• Outlier (ex. price = 0): มีค่ำผิดปกติหรือค่ำนอกเกณฑ์ เช่น รำคำ = 0 
• 'other' values: มีข้อมูลประเภทอื่น ๆ ที่ไม่ได้ระบุประเภท เช่น ค่ำ 'other' 
• Irregular model, manufacturer names: ชื่อรุ่นหรือผู้ผลิตที่ไม่อยู่ในรูปแบบเดียวกัน เช่น มีกำร
เขียนชื่อเป็นตัวย่อ

1. การเตรียมและการจัดการข้อมูล 
กำรประยุกต์ใช้เทคนิค log transformation ควบคู่กับ IQR ส่งผลให้ประสิทธิภำพของ model
ทุกประเภทพัฒนำขึ้นอย่ำงชัดเจน โดยเฉพำะอย่ำงยิ่งในกรณีของ XGBoost เนื่องจำกชุดข้อมูลที่ใช้มี
ลักษณะกำรกระจำยตัวแบบเบ้ กำรแปลงข้อมูลด้วยลอกำริทึมจึงช่วยปรับกำรกระจำยตัวของข้อมูลให้เข้ำ
ใกล้กำรแจกแจงแบบปกติมำกยิ่งขึ้น 
 
กำรท ำ Feature engineering ด้วยเทคนิค Clustering ไม่ได้ส่งผลในกำรปรับปรุงประสิทธิภำพ
ของชุดข้อมูลอย่ำงมีนัยส ำคัญ เนื่องจำกคุณลักษณะเหล่ำนี้จะถูก drop ออกในกระบวนกำรคัดเลือก
คุณลักษณะในขั้นตอนถัดไปอยู่แล้ว ดังนั้นเรำจึงสำมำรถข้ำมกระบวนกำร Clustering ได้โดยไม่ส่งผล
กระทบต่อประสิทธิภำพโดยรวมของ model 
2. การสร้างแบบจ าลอง 
จำกชุดข้อมูลไม่มี linear relationships ที่ชัดเจน ส่งผลให้ linear-based models ที่ใช้มี
ประสิทธิภำพที่น้อยลง โดยในทำงกลับกันแบบจ ำลอง Tree-based models มีควำมเหมำะสมมำกกว่ำ 
เนื่องจำกสำมำรถจัดกำรกับรูปแบบควำมสัมพันธ์ที่ไม่เป็นเส้นตรงได้อย่ำงมีประสิทธิภำพผ่ำนกำรแบ่งแบบ 
threshold-based decision 
จำกกำร Train พบว่ำ XGBoost เป็นแบบแบบจ ำลองที่ดีที่สุดหลังจำกกำรปรับค่ำพำรำมิเตอร์ 
โดยมีค่ำ R² อยู่ที่ 93.94% และมีค่ำ %MAE ที่ 8.58% 
 
โดยสรุป หลังจำกก ำจัดค่ำผิดปกติแล้ว ชุดข้อมูลยังคงมีลักษณะเบ้ขวำ ซึ่งท ำให้ model มีควำม
แม่นย ำสูงในบริเวณที่ข้อมูลมีกำรกระจุกตัว และมีควำมแม่นย ำน้อยลงในบริเวณที่ข้อมูลของกำรกระจำย
