### 1. สระอำ (U+0E33) หายกลายเป็นสระอา — const_2564 (Critical)

**อาการ:** คำที่มีสระอำทุกคำถูกอ่านออกมาเป็นสระอา โดยส่วนที่เป็น ม. (U+0E21) หายไป

**ตัวอย่างจากไฟล์จริง (page 2, cleaned_text):**
```
"จ านวนห้าร้อยคน"        ← ควรเป็น "จำนวนห้าร้อยคน"
"จ านวนสี่ร้อยคน"         ← ควรเป็น "จำนวนสี่ร้อยคน"
"ก าหนดสภาผู้แทนราษฎร"   ← ควรเป็น "กำหนดสภาผู้แทนราษฎร"
"ต าแหน่ง"                ← ควรเป็น "ตำแหน่ง"
"ท า"                     ← ควรเป็น "ทำ"
"ค านวณ"                  ← ควรเป็น "คำนวณ"
"น า"                     ← ควรเป็น "นำ"
"ล าดับ"                  ← ควรเป็น "ลำดับ"
```

**สาเหตุ:** PDF รัฐธรรมนูญ 2564 ผลิตด้วย font encoding แบบ Type 1 หรือ TrueType ที่ฝัง glyph สระอำเป็น two-part character (สระอา + ม) แต่ PyMuPDF ดึงออกมาแล้ว ม. หลุดหายไป เหลือแต่สระอา เป็น bug ที่รู้จักกันดีใน PDF ภาษาไทยที่ผลิตแบบเก่า

**ผลกระทบ:** ทุก ม. ที่ตามหลังสระอา หายไปทั้งหมด ส่งผลให้คำหลายร้อยคำในเอกสารอ่านผิด รวมถึง "จำนวน" "กำหนด" "ตำแหน่ง" "ทำ" "นำ" ซึ่งเป็นคำที่ใช้บ่อยมากในภาษากฎหมาย

**หมายเหตุ:** ในเอกสารจริงที่เห็นบนหน้าจอ อักษรแสดงถูกต้องเพราะ font glyph วาดถูก แต่เมื่อ copy หรือ extract ข้อความ character ที่ได้คือ Unicode code point ที่ต่างออกไป

## สาเหตุและแนวทางแก้ไข

### ปัญหา const_2564: สระอำหาย

สาเหตุคือ PDF ใช้ glyph แบบ ligature สำหรับสระอำ ซึ่ง PyMuPDF ไม่สามารถ decompose ออกมาได้ถูกต้อง

**วิธีแก้ไขที่แนะนำ:**

```python
import re

def fix_am_vowel(text: str) -> str:
    """
    แก้ไขสระอำที่หาย: "จ า" -> "จำ"
    Pattern: พยัญชนะ + สระอา + ช่องว่าง + พยัญชนะ
    กรณีนี้ "จ า" ถูก extract เป็น consonant + space + sara-a
    แต่จริงๆ ควรเป็น consonant + sara-am
    """
    # Pattern: พยัญชนะไทย + space + า + space
    # ซึ่งมาจาก สระอำ ที่ ม. หาย
    sara_a = '\u0e32'  # า
    sara_am = '\u0e33'  # ำ
    
    # "x า" ที่มาจาก x + sara-am ซึ่ง ม. หาย
    # ต้องดูบริบทว่า า นั้นตามหลัง space หรือไม่
    # แล้ว space นั้นคือ ม. ที่หายไป
    text = re.sub(r'([ก-ฮ]) า', r'\1ำ', text)
    return text
```

> หมายเหตุ: pattern นี้ต้องทดสอบอย่างระมัดระวัง เพราะ "x า" อาจเกิดจากการตัดบรรทัดปกติได้ด้วย ควร apply เฉพาะกรณีที่อยู่กลางบรรทัดเดียวกัน

### ปัญหา const_2550: วรรณยุกต์/สระหาย

นี่เป็นปัญหา font encoding ระดับ PDF ที่แก้ไขยาก เพราะต้องรู้ mapping ของ glyph ใน font นั้นๆ

**วิธีแก้ไขที่เป็นไปได้:**
1. ใช้ `pdfplumber` แทน PyMuPDF — บางครั้งให้ผลต่างกัน
2. ใช้ `pdf2image` แปลง PDF เป็นภาพ แล้วผ่าน OCR (Typhoon OCR) แทนการ extract ข้อความตรง
3. ใช้ pythainlp ตรวจสอบและเติมวรรณยุกต์อัตโนมัติ (accuracy ต่ำ)

**สำหรับ const_2550 โดยเฉพาะ:** เนื่องจากไฟล์ text_pdf แต่มีปัญหา encoding รุนแรง ควรพิจารณา **reprocess ด้วย OCR** แทน text extraction

### ปัญหา Header/Footer

```python
def remove_royal_gazette_header(text: str) -> str:
    """ลบ header/footer ราชกิจจานุเบกษา"""
    import re
    patterns = [
        r'[้่]?หนา?\s*[\u0E00-\u0E7F๐-๙\d]+\s*\n',
        r'[้่]?เลม?\s*[\u0E00-\u0E7F๐-๙\d]+\s*ตอนที่.*?\n',
        r'ราชกิจจานุเบกษา\s*\n',
        r'[\u0E00-\u0E7F]+\s+[\u0E50-\u0E59]+\s+[\u0E00-\u0E7F]+\s+[\u0E50-\u0E59]{4}\s*\n',
    ]
    for p in patterns:
        text = re.sub(p, '', text, flags=re.MULTILINE)
    return text.strip()
```
