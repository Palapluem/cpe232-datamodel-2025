ฉบับพิเศษ หน้า ๕๐
เล่ม ๙๑ ตอนที่ ๑๖๘ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๑๔๑ ภายใต้บังคับมาตรา ๑๔๐ การเรียกประชุม การขยายเวลาประชุม และการปิดประชุมรัฐสภา ให้กระทำโดย พระราชกฤษฎีกา

มาตรา ๑๔๒ ในระหว่างสมัยประชุม ห้ามมิให้จับหรือ คุมขัง หรือหมายเรียกตัวสมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน ราษฎรไปทำการสอบสวน ในฐานะที่สมาชิกผู้นั้นเป็นผู้ต้องหา ในคดีอาญา เว้นแต่ในกรณีที่ได้รับอนุญาตจากสภาที่ผู้นั้นเป็น สมาชิกหรือในกรณีที่จับในขณะกระทำความผิด

ในกรณีที่มีการจับสมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน ราษฎรในขณะกระทำความผิด ให้รายงานไปยังประธานแห่งสภา ที่ผู้นั้นเป็นสมาชิกโดยด่วน และประธานแห่งสภาที่ผู้นั้นเป็น สมาชิกอาจสั่งให้ปล่อยผู้ถูกจับได้

มาตรา ๑๔๓ ในกรณีที่มีการฟ้องสมาชิกวุฒิสภาหรือ สมาชิกสภาผู้แทนราษฎรในคดีอาญา ไม่ว่าจะได้ฟ้องนอกหรือ ในสมัยประชุม ศาลจะพิจารณาคดีนั้นในระหว่างสมัยประชุม มิได้ เว้นแต่จะได้รับอนุญาตจากสภาที่ผู้นั้นเป็นสมาชิก แต่การ พิจารณาคดีต้องไม่เป็นการขัดขวางต่อการที่สมาชิกผู้นั้นจะมา เข้าประชุมสภา
