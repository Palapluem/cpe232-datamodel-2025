ฉบับพิเศษ หน้า ๘ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๑๓ พระมหากษัตริย์ทรงดำรงตำแหน่งจอมทัพไทย
มาตรา ๑๔ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะ
สถาปนาฐานันดรศักดิ์ และพระราชทานเครื่องราชอิสริยาภรณ์
มาตรา ๑๕ พระมหากษัตริย์ทรงเลือกและแต่งตั้งผู้ทรง
คุณวุฒิเป็นประธานองคมนตรีคนหนึ่ง และองคมนตรีอื่นอีก
ไม่เกินกว่าสิบสี่คน ประกอบเป็นคณะองคมนตรี
คณะองคมนตรีมีหน้าที่ถวายความเห็นต่อพระมหากษัตริย์
ในพระราชกรณียกิจทั้งปวงที่พระมหากษัตริย์ทรงปรึกษา และ
มีหน้าที่อื่นตามที่บัญญัติในรัฐธรรมนูญนี้
มาตรา ๑๖ การเลือกและแต่งตั้งองคมนตรีก็ดี การให้
องคมนตรีพ้นจากตำแหน่งก็ดี ให้เป็นไปตามพระราชอัธยาศัย
ให้ประธานรัฐสภาเป็นผู้ลงนามรับสนองพระบรมราช
โองการแต่งตั้งประธานองคมนตรี หรือให้ประธานองคมนตรี
พ้นจากตำแหน่ง และให้ประธานองคมนตรีเป็นผู้ลงนาม
รับสนองพระบรมราชโองการแต่งตั้งองคมนตรีอื่น หรือ
ให้ออกมณตรีอื่นพ้นจากตำแหน่ง
มาตรา ๑๗ องคมนตรีต้องไม่เป็นสมาชิกวุฒิสภา สมาชิก
สภาผู้แทนราษฎร ข้าราชการซึ่งมีตำแหน่งหรือเงินเดือนประจำ
พนักงานรัฐวิสาหกิจ หรือสมาชิกหรือเจ้าหน้าที่ในพรรค
การเมือง และต้องไม่แสดงการฝักใฝ่ในพรรคการเมืองใด ๆ
