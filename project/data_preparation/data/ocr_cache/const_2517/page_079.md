ฉบับพิเศษ หน้า ๗๙ เล่ม ๔๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๓ ตุลาคม ๒๕๑๗

ผู้พิพากษามาแล้ว และต้องไม่ดำรงตำแหน่งข้าราชการการเมือง ไม่เป็นสมาชิกวุฒิสภา สมาชิกสภาผู้แทนราษฎรหรือทนายความ อีกสี่คน

ตำแหน่งของข้าราชการตุลาการผู้มีสิทธิได้รับเลือกเป็น กรรมการตุลาการผู้ทรงคุณวุฒิและการเลือกตั้งกรรมการตุลาการ ผู้ทรงคุณวุฒิ ให้เป็นไปตามกฎหมายว่าด้วยระเบียบข้าราชการ ฝ่ายตุลาการ

มาตรา ๒๑๑ ศาลทหารมีอำนาจพิจารณาพิพากษาคดีตาม ที่กฎหมายบัญญัติ

การแต่งตั้งและการให้ตุลาการศาลทหารพ้นจากตำแหน่ง ให้เป็นไปตามที่กฎหมายบัญญัติ

มาตรา ๒๑๒ ศาลปกครองและศาลในสาขาแรงงาน สาขา ภาษี หรือสาขาสังคม จะตั้งขึ้นได้ก็แต่โดยพระราชบัญญัติ

การแต่งตั้งและการให้ผู้พิพากษาพ้นจากตำแหน่ง อำนาจ หน้าที่ของศาลตลอดจนวิธีพิจารณาของศาลตามวรรคหนึ่ง ให้ เป็นไปตามกฎหมายว่าด้วยการจัดตั้งศาลนั้น

มาตรา ๒๑๓ ในกรณีที่มีปัญหาเกี่ยวกับอำนาจหน้าที่ ระหว่างศาลยุติธรรมกับศาลอื่น หรือระหว่างศาลอื่นด้วยกัน ให้คณะตุลาการรัฐธรรมนูญเป็นผู้วินิจฉัย
