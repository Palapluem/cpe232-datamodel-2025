ฉบับพิเศษ หน้า ๑๑ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๒๔ ก่อนเข้ารับหน้าที่ ผู้สำเร็จราชการแทน พระองค์ซึ่งได้รับการแต่งตั้งตามมาตรา ๒๑ หรือมาตรา ๒๒ ต้องปฏิญาณตนในที่ประชุมรัฐสภา ด้วยถ้อยคำดังต่อไปนี้
"ข้าพเจ้า ( ชื่อผู้ปฏิญาณ ) ขอปฏิญาณว่า ข้าพเจ้าจะ จงรักภักดีต่อพระมหากษัตริย์ ( พระปรมาภิไธย ) และจะ ปฏิบัติหน้าที่ด้วยความซื่อสัตย์สุจริต เพื่อประโยชน์ของประเทศ และประชาชน ทั้งจะรักษาไว้และปฏิบัติตามซึ่งรัฐธรรมนูญ แห่งราชอาณาจักรไทยทุกประการ "
มาตรา ๒๕ การสืบราชสมบัติให้เป็นไปโดยนัยแห่ง กฎมณเทียรบาลว่าด้วยการสืบราชสันตติวงศ์ พระพุทธศักราช ๒๔๖๗ และประกอบด้วยความเห็นชอบของรัฐสภา หากไม่มี พระราชโอรส รัฐสภาอาจให้ความเห็นชอบในการให้พระราช ธิดาสืบราชสันตติวงศ์ก็ได้
การแก้ไขเพิ่มเติมกฎมณเทียรบาลว่าด้วยการสืบราช สันตติวงศ์ พระพุทธศักราช ๒๔๖๗ ให้กระทำได้โดยวิธีการ อย่างเดียวกันกับการแก้ไขเพิ่มเติมรัฐธรรมนูญ
มาตรา ๒๖ ในกรณีที่ราชบัลลังก์หากว่างลง ให้คณะ องคมนตรีเสนอพระนามผู้สืบราชสันตติวงศ์ตามกฎมณเทียร- บาลว่าด้วยการสืบราชสันตติวงศ์ พระพุทธศักราช ๒๔๖๗ ต่อ รัฐสภาเพื่อขอความเห็นชอบ เมื่อรัฐสภาให้ความเห็นชอบแล้ว
