ฉบับพิเศษ หน้า ๕๙ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๑๕๖ วุฒิสภา และสภาผู้แทนราษฎรมีอำนาจ ควบคุมการบริหารราชการแผ่นดิน โดยบทบัญญัติแห่ง รัฐธรรมนูญนี้

มาตรา ๑๕๗ ในที่ประชุมวุฒิสภาหรือสภาผู้แทนราษฎร สมาชิกทุกคนมีสิทธิตั้งกระทู้ถามรัฐมนตรีในเรื่องใดเกี่ยวกับงาน ในหน้าที่ได้ แต่รัฐมนตรีย่อมมีสิทธิที่จะไม่ตอบ เมื่อคณะ รัฐมนตรีเห็นว่าเรื่องนั้นยังไม่ควรเปิดเผย เพราะเกี่ยวกับความ ปลอดภัยหรือประโยชน์สำคัญของแผ่นดิน

มาตรา ๑๕๘ สมาชิกสภาผู้แทนราษฎรจำนวนไม่น้อยกว่า หนึ่งในห้าของจำนวนสมาชิกทั้งหมดของสภาผู้แทนราษฎร มี สิทธิเข้าชื่อเสนอญัตติขอให้เปิดอภิปรายทั่วไป เพื่อให้คณะ รัฐมนตรีแถลงข้อเท็จจริง หรือแสดงความคิดเห็นในปัญหา อันเกี่ยวกับการบริหารราชการแผ่นดิน

ญัตติดังกล่าวในวรรคหนึ่งให้ยื่นต่อประธานสภาผู้แทน ราษฎร และให้ประธานสภาผู้แทนราษฎรแจ้งไปยังนายกรัฐมนตรี เพื่อกำหนดเวลาสำหรับการเปิดอภิปรายทั่วไป ซึ่งต้องไม่ช้ากว่า สามสิบวันนับแต่วันที่นายกรัฐมนตรีได้รับแจ้ง แต่คณะ รัฐมนตรีย่อมมีสิทธิที่จะขอให้ระงับการเปิดอภิปรายทั่วไปนั้น
