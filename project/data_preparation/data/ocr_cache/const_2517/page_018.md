ฉบับพิเศษ หน้า ๑๘ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

การสืบมรดกย่อมได้รับความคุ้มครอง สิทธิของบุคคลใน การสืบมรดกย่อมเป็นไปตามบทบัญญัติแห่งกฎหมาย

การเวนคืนอสังหาริมทรัพย์ จะกระทำมิได้ เว้นแต่โดย อาศัยอำนาจตามบทบัญญัติแห่งกฎหมาย เฉพาะเพื่อการอันเป็น สาธารณูปโภค หรือการอันจำเป็นในการป้องกันประเทศ หรือ การได้มาซึ่งทรัพยากรธรรมชาติ หรือเพื่อการผังเมือง หรือเพื่อ การพัฒนาการเกษตรหรือการอุตสาหกรรม หรือเพื่อการปฏิรูป ที่ดิน หรือเพื่อประโยชน์สาธารณะอย่างอื่น และต้องชดใช้ ค่าทำขวัญภายในเวลาอันควรแก่เจ้าของตลอดจนผู้ทรงสิทธิ บรรดาที่ได้รับความเสียหายในการเวนคืนนั้น ทั้งนี้ตามที่ระบุ ไว้ในกฎหมาย

การกำหนดค่าทำขวัญตามวรรคสามให้คำนึงถึงการได้มา สภาพและที่ตั้งของอสังหาริมทรัพย์ ประกอบกับเหตุและวัตถุ ประสงค์ของการเวนคืนเพื่อให้เกิดความเป็นธรรมแก่สังคม

มาตรา ๔๐ บุคคลย่อมมีเสรีภาพในการพูด การเขียน การพิมพ์และการโฆษณา

การจำกัดเสรีภาพเช่นว่านี้จะกระทำมิได้ เว้นแต่โดยอาศัย อำนาจตามบทบัญญัติแห่งกฎหมาย เฉพาะเพื่อรักษาความ
