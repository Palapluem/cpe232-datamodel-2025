ฉบับพิเศษ หน้า ๒๓ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๔๙ สิทธิของบุคคลในครอบครัวย่อมได้รับความคุ้มครอง

มาตรา ๕๐ บุคคลคนเดียวหรือหลายคนร่วมกันย่อมมีสิทธิเสนอเรื่องราวร้องทุกข์ ภายในเงื่อนไขและวิธีการที่กฎหมายบัญญัติ

มาตรา ๕๑ สิทธิของบุคคลที่จะฟ้องหน่วยราชการซึ่งเป็นนิติบุคคลให้รับผิดเพื่อการกระทำของเจ้าพนักงาน ย่อมได้รับความคุ้มครอง

มาตรา ๕๒ บุคคลซึ่งเป็นทหาร ตำรวจ ข้าราชการ และพนักงานส่วนท้องถิ่น ย่อมมีสิทธิและเสรีภาพตามรัฐธรรมนูญ เช่นเดียวกับประชาชนพลเมือง เว้นแต่ที่จำกัดในกฎหมายหรือกฎหมายข้อบังคับที่ออกโดยอาศัยอำนาจกฎหมาย เฉพาะในส่วนที่เกี่ยวกับการเมือง สมรรถภาพหรือวินัย

มาตรา ๕๓ บุคคลจะใช้สิทธิและเสรีภาพตามรัฐธรรมนูญให้เป็นปฏิปักษ์ต่อชาติ ศาสนา พระมหากษัตริย์และรัฐธรรมนูญมิได้
