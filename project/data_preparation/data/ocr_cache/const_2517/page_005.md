ฉบับพิเศษ หน้า ๕ เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

ได้อย่างแท้จริงก็ต่อเมื่อประชาชนทั้งมวลมีความเชื่อมั่นว่า การปกครองระบอบประชาธิปไตยนี้เป็นระบบการปกครองที่ดี และเหมาะสมสำหรับประเทศเราในอันที่จะยังให้เกิดความผาสุกแก่ปวงชนโดยทั่วกัน เพราะเหตุนี้ปวงชนจึงต้องร่วมกันมีส่วนมีเสียงในการปกครองประเทศ โดยเคารพต่อเจตนารมณ์ของรัฐธรรมนูญนี้อย่างเคร่งครัด และต้องพร้อมที่จะเสียสละประโยชน์สุขส่วนตนเพื่อประโยชน์สุขอันร่วมกัน ทั้งเมื่อถึงวาระจำเป็น จักต้องพร้อมที่จะอุทิศแม้ชีวิตและเลือดเนื้อเพื่อรักษาไว้ซึ่งระบอบประชาธิปไตยนี้

เมื่อสภานิติบัญญัติแห่งชาติได้พิจารณาปรับปรุงแก้ไขร่างรัฐธรรมนูญอย่างรอบคอบแล้ว ได้มีมติเห็นชอบและได้นำขึ้นทูลเกล้าทูลกระหม่อมถวายเพื่อทรงลงพระปรมาภิไธยให้ประกาศใช้เป็นรัฐธรรมนูญแห่งราชอาณาจักรไทยสืบไป

เมื่อได้ทรงมีพระราชวิจารณ์ร่างรัฐธรรมนูญโดยถี่ถ้วนทั่วกระบวนความแล้ว ทรงมีพระราชดำริเห็นสมควรพระราชทานพระบรมราชานุมัติตามคำแนะนำและยินยอมของสภานิติบัญญัติแห่งชาติ

จึงมีพระบรมราชโองการดำรัสเหนือเกล้าเหนือกระหม่อมให้ตรารัฐธรรมนูญแห่งราชอาณาจักรไทยฉบับนี้ขึ้นไว้ ให้ใช้แทนธรรมนูญการปกครองราชอาณาจักร พุทธศักราช ๒๕๑๕
