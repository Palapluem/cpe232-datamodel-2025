ให้นำบทบัญญัติมาตรา ๑๐๕ และมาตรา ๑๐๖ มาใช้บังคับ แก่การสิ้นสุดของความเป็นรัฐมนตรีตาม (๒) (๓) (๔) หรือ (๖)

มาตรา ๑๘๙ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจ ในการให้รัฐมนตรีพ้นจากความเป็นรัฐมนตรี ตามที่นายก รัฐมนตรีถวายคำแนะนำ
