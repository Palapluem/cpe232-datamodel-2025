ฉบับพิเศษ หน้า ๒๖
เล่ม ๙๑ ตอนที่ ๑๖๙ ราชกิจจานุเบกษา ๗ ตุลาคม ๒๕๑๗

มาตรา ๖๘ กำลังทหารพึงมีโดยเหมาะสมแก่ความจำเป็น สำหรับรักษาเอกราช ความมั่นคงและผลประโยชน์แห่งชาติ

มาตรา ๖๙ กำลังทหารเป็นของชาติ ไม่ขึ้นต่อเอกชน หรือคณะบุคคลใด ๆ

มาตรา ๗๐ กำลังทหารพึงใช้เพื่อการรบหรือการสงคราม เพื่อปกป้องสถาบันพระมหากษัตริย์ เพื่อการปราบปรามการกบฏ และการจลาจล เพื่อการรักษาความมั่นคงของรัฐและเพื่อการ พัฒนาประเทศชาติ

การใช้กำลังทหารเพื่อการอื่น ให้เป็นไปตามบทบัญญัติ แห่งกฎหมาย

มาตรา ๗๑ รัฐจะต้องรักษากฎหมายและความสงบเรียบร้อย เพื่อให้ประชาชนมีความปลอดภัยในชีวิต ร่างกายและ ทรัพย์สิน และในการดำเนินชีวิตโดยปกติสุข

มาตรา ๗๒ รัฐพึงส่งเสริมและบำรุงการศึกษาอบรม การจัดระบบการศึกษาอบรมเป็นหน้าที่ของรัฐโดยเฉพาะ สถานศึกษาทั้งปวงย่อมอยู่ภายใต้การควบคุมดูแลของรัฐ

การศึกษาอบรมชั้นอุดมศึกษา รัฐพึงจัดการให้สถานศึกษา ดำเนินกิจการของตนเองได้ภายในขอบเขตที่กฎหมายบัญญัติ
