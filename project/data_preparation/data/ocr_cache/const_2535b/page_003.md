เล่ม ๑๐๙ ตอนที่ ๗๒ ราชกิจจานุเบกษา ๓๐ มิถุนายน ๒๕๓๕

หมายเหตุ :- เหตุผลในการประกาศใช้รัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไข แต่เดิมฉบับนี้ คือ โดยที่เป็นการสมควรแก้ไขเพิ่มเติมรัฐธรรมนูญแห่งราชอาณา จักรี เพื่อกำหนดให้การประชุมในสมัยประชุมสามัญประจำปีครั้งที่สองของ กา วุฒิสภา และสภาผู้แทนราษฎร สามารถพิจารณาเรื่องอื่นใดในอำนาจหน้าที่ รัฐสภา วุฒิสภา และสภาผู้แทนราษฎรได้ จึงจำเป็นต้องตรารัฐธรรมนูญนี้
