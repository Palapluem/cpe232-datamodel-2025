มาตรา ๓ ให้เพิ่มความต่อไปนี้เป็น (๑๕) (๑๖) และ (๑๗)

ซึ่งแก้ไขเพิ่มเติมโดยรัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไขเพิ่มเติม
