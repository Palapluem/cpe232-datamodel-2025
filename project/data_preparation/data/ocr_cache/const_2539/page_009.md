เล่ม ๑๑๓ ตอนที่ ๕๓ ก ราชกิจจานุเบกษา ๒๒ ตุลาคม ๒๕๓๙
หน้า ๙

ร่างรัฐธรรมนูญปฏิบัติหน้าที่ได้ต่อไปโดยไม่ต้องดำเนินการเลือกตั้งแทน
ตำแหน่งที่ว่างนั้น แต่ทั้งนี้สภาร่างรัฐธรรมนูญจะต้องมีจำนวนสมาชิก
เหลืออยู่ไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกตามมาตรา ๒๑๑ ทวิ (๑)
และ (๒)

มาตรา ๒๑๑ เอกาทศ สภาร่างรัฐธรรมนูญ มีประธานสภาร่าง
รัฐธรรมนูญคนหนึ่งและรองประธานคนหนึ่งหรือสองคน ซึ่งพระมหากษัตริย์
ทรงแต่งตั้งจากสมาชิกแห่งสภาร่างรัฐธรรมนูญตามมติของสภาร่างรัฐธรรมนูญ
และให้ประธานรัฐสภาเป็นผู้ลงนามรับสนองพระบรมราชโองการ

ประธานสภาร่างรัฐธรรมนูญมีอำนาจหน้าที่ดำเนินกิจการของสภา
ร่างรัฐธรรมนูญตามหมวดนี้ รองประธานมีอำนาจหน้าที่ตามที่ประธาน
มอบหมาย และปฏิบัติหน้าที่แทนประธานเมื่อประธานไม่อยู่หรือไม่สามารถ
ปฏิบัติหน้าที่ได้

เมื่อประธานและรองประธานไม่อยู่ในที่ประชุม ให้สมาชิกแห่งสภา
ร่างรัฐธรรมนูญเลือกตั้งกันขึ้นเองเป็นประธานในคราวประชุมนั้น

มาตรา ๒๑๑ ทวาทศ เงินประจำตำแหน่งและประโยชน์ตอบแทน
อย่างอื่นของประธานและรองประธานสภาร่างรัฐธรรมนูญ สมาชิกสภาร่าง
รัฐธรรมนูญและกรรมาธิการที่สภาร่างรัฐธรรมนูญแต่งตั้ง ให้เป็นไปตามที่
กำหนดโดยพระราชกฤษฎีกา

มาตรา ๒๑๑ เตรส สภาร่างรัฐธรรมนูญจะต้องจัดทำร่างรัฐธรรมนูญ
ให้แล้วเสร็จภายในกำหนดเวลาสองร้อยสี่สิบวันนับแต่วันที่มีสมาชิกสภา
ร่างรัฐธรรมนูญครบจำนวนตามมาตรา ๒๑๑ ทวิ
