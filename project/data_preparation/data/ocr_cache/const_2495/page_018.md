ฉบับพิเศษ หน้า ๑๘
ตอนที่ ๑๕ เล่ม ๖๙ ราชกิจจานุเบกษา ๘ มีนาคม ๒๔๙๕

"มาตรา ๕๐ สมาชิกภาพแห่งสภาผู้แทนราษฎรสิ้นสุดลง เมื่อ
(๑) ถึงคราวออกตามวาระ หรือยุบสภา
(๒) ตาย
(๓) ลาออก
(๔) ขาดคุณสมบัติหรือมีลักษณะต้องห้ามสำหรับผู้สมัครรับเลือกตั้ง ตามที่บัญญัติไว้ในกฎหมายว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราษฎร
(๕) สภาผู้แทนราษฎรวินิจฉัยให้ออกจากตำแหน่ง โดยเห็นว่ามีความประพฤติในทางจะนำมาซึ่งความเสื่อมเสียแก่สภา มติในข้อนี้ต้องมีเสียงไม่ต่ำกว่าสองในสามของจำนวนสมาชิกที่มาประชุม

การวินิจฉัยชี้ขาดตาม (๔) ให้ศาลฎีกาวินิจฉัยตามวิธีการที่กฎหมายกำหนด - แต่การชี้ขาดของศาลฎีกาย่อมไม่กระทบกระเทือนการที่สมาชิกนั้นได้ปฏิบัติหน้าที่ในสภาก่อนที่มีการชี้ขาด"

"มาตรา ๖๒ ในระหว่างสมัยประชุม ห้ามมิให้จับ หรือคุมขัง หรือหมายเรียกดังสมาชิกสภาผู้แทนราษฎรไปทำการ
