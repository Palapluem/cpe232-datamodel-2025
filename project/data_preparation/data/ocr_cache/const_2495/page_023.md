ฉบับพิเศษ หน้า ๒๓
ตอนที่ ๑๕ เล่ม ๖๙ ราชกิจจานุเบกษา ๘ มีนาคม ๒๔๙๕

นายกรัฐมนตรีได้รับแจ้ง แต่คณะรัฐมนตรีย่อมมีสิทธิที่จะขอให้ระงับการเปิดอภิปรายทั่วไปน้ำเสียได้ เมื่อเห็นว่าเป็นเรื่องที่ยังไม่ควรเปิดเผย เพราะเกี่ยวกับความปลอดภัยหรือประโยชน์สำคัญของแผ่นดิน

ในการเปิดอภิปรายทั่วไปตามมาตรานี้ สภาจะลงมติในปัญหาที่อภิปรายนี้ได้"

"มาตรา ๗๖ สมาชิกสภาผู้แทนราษฎรไม่ต่ำกว่าหนึ่งในสามของจำนวนสมาชิกทั้งหมด มีสิทธิเข้าชื่อเสนอญัตติขอเปิดอภิปรายทั่วไปเพื่อลงมติไม่ไว้วางใจรัฐมนตรีเป็นรายตัวหรือทั้งคณะ

เมื่อการเปิดอภิปรายทั่วไปในสภาสิ้นสุดลง โดยมิใช่ด้วยมติให้ผ่านระเบียบวาระเปิดอภิปรายนั้นไป ให้สภาผู้แทนราษฎรลงมติไว้วางใจหรือไม่ไว้วางใจ แต่การลงมติในกรณีเช่นนี้ มิให้กระทำในวันเดียวกันกับวันที่การอภิปรายสิ้นสุด"

มาตรา ๖ ความในหมวด ๔ ของรัฐธรรมนูญแห่งราชอาณาจักรไทย ฉบับพุทธศักราช ๒๔๗๕ ให้แก้ไขเพิ่มเติมดังต่อไปนี้
