ฉบับพิเศษ หน้า ๔๐
ตอนที่ ๑๕ เล่ม ๖๙ ราชกิจจานุเบกษา ๘ มีนาคม ๒๔๙๕

มาตรา ๑๑ บรรดามาตราต่าง ๆ ของรัฐธรรมนูญแห่งราชอาณาจักรไทย ฉบับพุทธศักราช ๒๔๗๕ ซึ่งได้มีการแก้เลขา มาตราตามรัฐธรรมนูญนี้แล้วนั้น ถ้าได้อ้างถึงบทมาตราใดของ รัฐธรรมนูญแห่งราชอาณาจักรไทย ฉบับพุทธศักราช ๒๔๗๕ ให้ ถือว่าอ้างถึงบทมาตราตามที่แก้เลขมาตราใหม่นั้น
