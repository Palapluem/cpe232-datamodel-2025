ฉบับพิเศษ หน้า ๘
เล่ม ๑๐๘ ตอนที่ ๔๐ ราชกิจจานุเบกษา • มีนาคม ๒๕๓๔

มาตรา ๑๗ พระมหากษัตริย์ทรงตราพระราชบัญญัติโดยคำแนะนำ และยินยอมของสภานิติบัญญัติแห่งชาติ
ร่างพระราชบัญญัติจะเสนอได้ก็แต่โดยคณะรัฐมนตรี

มาตรา ๑๘ ให้มีสาระรักษาความสงบเรียบร้อยแห่งชาติ ประกอบ ด้วยบุคคลตามประกาศของคณะรักษาความสงบเรียบร้อยแห่งชาติ ฉบับที่ ๒ ลงวันที่ ๒๓ กุมภาพันธ์ พ.ศ. ๒๕๓๔ และประกาศของคณะรักษา ความสงบเรียบร้อยแห่งชาติ ฉบับที่ ๕ ลงวันที่ ๒๓ กุมภาพันธ์ พ.ศ. ๒๕๓๔ เป็นกรรมการ
ประธานสาระรักษาความสงบเรียบร้อยแห่งชาติ อาจแต่งตั้ง กรรมการสาระรักษาความสงบเรียบร้อยแห่งชาติเพิ่มขึ้นได้อีกไม่เกินสิบ ห้าคน
ให้หัวหน้าคณะรักษาความสงบเรียบร้อยแห่งชาติเป็นประธานสภา รักษาความสงบเรียบร้อยแห่งชาติ รองหัวหน้าคณะรักษาความสงบ เรียบร้อยแห่งชาติคนหนึ่งซึ่งสาระรักษาความสงบเรียบร้อยแห่งชาติแต่งตั้ง เป็นรองประธานสาระรักษาความสงบเรียบร้อยแห่งชาติ และให้เลขาธิการ คณะรักษาความสงบเรียบร้อยแห่งชาติเป็นเลขาธิการสาระรักษาความสงบ เรียบร้อยแห่งชาติ
ให้สาระรักษาความสงบเรียบร้อยแห่งชาติแต่งตั้งบุคคลซึ่งเป็นหรือ ไม่ได้เป็นกรรมการสาระรักษาความสงบเรียบร้อยแห่งชาติ เป็นรองเลขา ธิการสาระรักษาความสงบเรียบร้อยแห่งชาติคนหนึ่งหรือหลายคนก็ได้
