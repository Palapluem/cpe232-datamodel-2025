อำนาจนิติบัญญัติ
ส่วนที่ ๑
บททั่วไป

มาตรา ๒๖ รัฐสภาประกอบด้วย วุฒิสภา และสภาผู้แทน ไม่ว่าจะประชุมแยกกันหรือร่วมกัน

มาตรา ๒๗ ร่างพระราชบัญญัติทั้งหลายจะตราขึ้นเป็นกฎหมายได้ด้วยคำแนะนำและยินยอมของรัฐสภา

มาตรา ๒๘ การตราพระราชบัญญัติขึ้น เป็น กฎหมายให้มีผลย้อนหลัง เป็นการลงโทษบุคคลในทางอาญา นั้นจะกระทำมิได้

มาตรา ๒๙ ร่างพระราชบัญญัติซึ่งรัฐสภาได้ทำขึ้นเสร็จแล้ว ให้นายกรัฐมนตรีนำขึ้นทูลเกล้า ฯ ถวาย เพื่อพระมหาภัตริย์ทรงลงพระปรมาภิไธย และเมื่อได้ประกาศในราชกิจจานุเบกษาแล้ว ให้ใช้บังคับเป็นกฎหมายได้

มาตรา ๓๐ ถ้าพระมหากษัตริย์ไม่ทรงเห็นชอบด้วยร่างพระราชบัญญัตินั้น จะได้พระราชทานคืนมายังรัฐสภา
