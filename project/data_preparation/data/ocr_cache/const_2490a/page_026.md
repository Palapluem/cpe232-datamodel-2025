ฉบับพิเศษ หน้า ๒๖
ตอนที่ ๕๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน - ๔๙๐

ตามมาตรา ๔๒ หรือรัฐสภาไม่ให้ความไว้วางใจตามมาตรา ๗๗ หรือเมื่อสภาผู้แทนชุดที่มีส่วนให้ความไว้วางใจแก่คณะรัฐมนตรีในขณะเข้ารับหน้าที่นั้นสุดสิ้นลง ในกรณีดังกล่าว หลังนี้และกรณีที่คณะรัฐมนตรีลาออกจากตำแหน่งเอง คณะรัฐมนตรีที่ออกนั้นต้องอยู่ในตำแหน่งเพื่อดำเนินงานไปจนกว่าจะตั้งคณะรัฐมนตรีขึ้นใหม่

มาตรา ๗๙ ความเป็นรัฐมนตรีสุดสิ้นลงเฉพาะตัวโดย
(๑) โดยพระบรมราชโองการ
(๒) ตาย
(๓) ลาออก
(๔) ขาดคุณสมบัติตามความในมาตรา ๘๑
(๕) รัฐสภาลงมติไม่ไว้วางใจ.

มาตรา ๘๐ ในเหตุฉุกเฉินที่มีความจำเป็นรีบด่วนอันจะรักษาความปลอดภัยสาธารณะหรือป้องปัดภัยพิบัติสาธารณะ และจะเรียกประชุมรัฐสภาให้ทันท่วงทีมิได้ก็ดี หรือกรณีเช่นว่านั้นเกิดขึ้นในระหว่างสภาผู้แทนถูกยุบก็ดี พระมหา
