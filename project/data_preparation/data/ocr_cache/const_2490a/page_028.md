มาตรา ๘๕ พระมหากษัตริย์ทรงพระราชอำนาจในการ พระราชทานอภัยโทษ

มาตรา ๘๖ พระมหากษัตริย์ทรงพระราชอำนาจในการ ตราพระราชกฤษฎีกา

มาตรา ๘๗ ภายใต้บังคับแห่งมาตรา ๕๖ และมาตรา ๗๔ บทกฎหมาย พระราชหัตถเลขาและพระบรมราชโองการ ใดอันเกี่ยวกับราชการแผ่นดิน ต้องมีรัฐมนตรีคนหนึ่งลงนามรับสนองพระบรมราชโองการ

มาตรา ๘๘ การพิจารณาพิพากษาอรรถคดีเป็นอำนาจ ของศาลโดยฉะเพาะ ซึ่งจะต้องดำเนินตาม กฎหมายและใน พระปรมาภิไธยพระมหากษัตริย์
