ฉบับพิเศษ หน้า ๑๖
ตอนที่ ๕๓ เล่ม ๒ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๔๙๐

อนึ่งในระหว่างเวลาเก้าสิบวันนั้นจะโปรดเกล้า ฯ ปิดประชุมก็ได้

มาตรา ๕๔ พระมหากษัตริย์ทรงเรียกประชุมวุฒิสภา และสภาผู้แทนตามสมัยประชุม ทรงปิดและเปิดประชุม

พิธีเปิดประชุมจะทรงพระกรุณาเสด็จดำเนิน มาทรงทำหรือจะโปรตเกล้า ฯ ให้รัชชทายาท ที่บรรลุนิติภาวะแล้ว หรือผู้ใดผู้หนึ่งกระทำพิธีแทนพระองค์ก็ได้

มาตรา ๕๕ เมื่อเป็นการจำเป็นเพื่อประโยชน์ของแผ่นดิน พระมหากษัตริย์จะทรงเรียกประชุมวิสามัญแห่งสภาทั้งสองก็ได้

มาตรา ๕๖ สมาชิกวุฒิสภาและสภาผู้แทนทั้งสองสภา หรือสมาชิกแต่ละสามีจำนวนไม่ต่ำกว่าหนึ่งในสามของสมาชิกของทั้งสองสภา มีสิทธิเข้าชื่อยืนร้องขอให้นำความกราบบังคมทูลขอให้ทรงเรียกประชุมวิสามัญแห่งสภาทั้งสองก็ได้
