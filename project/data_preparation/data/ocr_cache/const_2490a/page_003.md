ฉบับพิเศษ หน้า ๓
ตอนที่ ๕๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๔๙๐

ชาติอย่างไม่มีสุดสิ้น จนถึงกับว่าจะไม่ดำรงอยู่ในภาวะอันควรแก่ความเป็นไทยต่อไปอีกได้

ราษฎรไทยส่วนมากผู้สนใจต่อการนี้พร้อมด้วยทหารของชาติได้พร้อมใจกันนำความขึ้นกราบบังคมทูล ขอให้เลิกใช้รัฐธรรมนูญปัจจุบัน และประกาศใช้รัฐธรรมนูญฉบับใหม่ อันจะเป็นวิถีทางจรรโลงประเทศชาติให้วัฒนาถาวร อีกทั้งจะเป็นทางบำบัดยุคเข็ญของประชาชนทั้งปวงให้เข้าสู่ภาวะปกติได้สืบไป

จึงทรงพระกรุณาโปรดเกล้าโปรดกระหม่อมให้เลิกใช้รัฐธรรมนูญฉบับปัจจุบัน และให้ประกาศใช้รัฐธรรมนูญแห่งราชอาณาจักรไทยฉบับใหม่ตั้งแต่บัดนี้เป็นต้นไป

บททั่วไป

มาตรา ๑ ประเทศไทย เป็น ราชอาณาจักร อันหนึ่งอันเดียวจะแบ่งแยกมิได้

ประชาชนชาวไทยไม่ว่าเหล่ากำเนิดหรือศาสนาใดย่อมอยู่ในความคุ้มครองแห่งรัฐธรรมนูญนี้เสมอ กัน
