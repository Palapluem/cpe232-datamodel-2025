ฉบับพิเศษ หน้า ๒๒
ตอนที่ ๕๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๔๙๐

เป็นคณะกรรมาธิการวิสามัญ เพื่อกระทำกิจการหรือพิจารณาสอบสวนข้อความใด อันอยู่ในวงงานของสภาแล้วรายงานต่อสภา คณะกรรมาธิการที่กล่าวนี้ ย่อมมีอำนาจเรียกบุคคลใดมาชี้แจงแสดงความเห็น ในเรื่องกิจการที่กระทำหรือพิจารณาอยู่นั้นได้

เอกสิทธิ์ที่บัญญัติไว้ในมาตรา ๕๐ นั้น ให้คุ้มครองถึงบุคคลผู้ที่กระทำหน้าที่ตามมาตรานี้ด้วย

มาตรา ๖๘ การประชุมคณะกรรมาธิการตามมาตรา ๖๗ นั้น ต้องมีกรรมาธิการไม่ต่ำกว่าครึ่งจำนวนมาประชุม จึงเป็นองค์ประชุมได้

มาตรา ๖๙ วุฒิสภาและสภาผู้แทนมีอำนาจตั้งข้อบังคับการประชุมและการปรึกษา ของสภาเพื่อดำเนินการตามบทบัญญัติแห่งรัฐธรรมนูญนี้
