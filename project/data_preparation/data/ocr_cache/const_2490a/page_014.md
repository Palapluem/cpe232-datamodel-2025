ฉบับพิเศษ หน้า ๑๔
ตอนที่ ๕ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๕๕๐

มาตรา ๔๖ ประธานวุฒิสภาและประธานสภาผู้แทนมีหน้าที่ดำเนินกิจการของสถานนั้น ๆ ให้เป็นไปตามระเบียบรองประธานมีหน้าที่กำกับการแทนประธานหรือประธานไม่ อยู่หรือไม่สามารถปฏิบัติหน้าที่ได้

มาตรา ๔๗ ในเมื่อประธานและรองประธานวุฒิสภาหรือสภาผู้แทนไม่อยู่ในตัวประชุม ให้สมาชิกของสถานนั้น ๆ เลือกตั้งขึ้นเองเป็นประธานในการประชุมนั้น

มาตรา ๔๘ การประชุมของวุฒิสภาก็ดี หรือของสภาผู้แทนก็ดี ทุกความต้องเสียภาษีตามประชุมไม่ต่างว่าหน้าในสามของจำนวนสมาชิกทั้งหมด จึงจะเป็นองค์ประชุมได้

มาตรา ๔๙ การลงมติวินิจฉัยข้อปรึกษานั้น ให้ถือเอาเสียงข้างมากเป็นประมาณ เว้นแต่เรื่องซึ่งมีบทบัญญัติไว้เป็นพิเศษในรัฐธรรมนูญนี้

สมาชิกคนหนึ่งย่อมมีเสียงหนึ่งในการลงคะแนน ถ้ามีจำนวนเสียงละแทนเท่ากัน ให้ประธานในที่ประชุมออกเสียงเพิ่มขึ้นได้อีกเสียงหนึ่ง และเป็นเสียงชี้ขาด
