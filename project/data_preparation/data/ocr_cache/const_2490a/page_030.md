หมวด ๘
บทสุดท้าย

มาตรา ๙๔ รัฐสภาทรงไว้ซึ่งสิทธิเด็ดขาดในการตีความแห่งรัฐธรรมนูญนี้
มติในการตีความแห่งรัฐธรรมนูญนี้ ต้องมีเสียงเห็นด้วยไม่ต่ำกว่าครึ่งหนึ่งของจำนวนสมาชิกทั้งสองสำหรับกัน

มาตรา ๙๕ บทบัญญัติแห่งกฎหมายใดมีข้อความแย้งหรือขัดต่อรัฐธรรมนูญนี้ บทบัญญัตินั้นเป็นโมฆะ

บทฉะเพาะกาล

มาตรา ๙๖ ในวาระเริ่มแรก วุฒิสภาประกอบด้วยสมาชิกซึ่งพระมหากษัตริย์ทรงเลือกตั้ง ภายในกำหนด ๕ วันนับตั้งแต่วันใช้รัฐธรรมนูญนี้ และถ้าจำเป็นจะทำการประชุมวุฒิสภาก็ได้ ซึ่งในกรณีนี้ให้วุฒิสภามีอำนาจตามบทบัญญัติแห่งรัฐธรรมนูญนี้จะสำเร็จเรียบร้อย
