หมวด ๒
อภิรัฐมนตรี

มาตรา ๑๓ อภิรัฐมนตรีเป็นตำแหน่งประจำมีห้านาย เป็นผู้บริหารราชการในพระองค์ และถวายคำปรึกษาแต่ พระมหากษัตริย์

มาตรา ๑๔ อภิรัฐมนตรีเป็นที่ปรึกษาของพระมหา กษัตริย์ด้วยการถวายความเห็นโดยชอบและถูกต้อง เพื่อ ประโยชน์แก่ประเทศชาติทุกสาขา

มาตรา ๑๕ ในคณะอภิรัฐมนตรีจะทรงพระกรุณา แต่งตั้งผู้อาวุโสเป็นประธานคณะหนึ่งนาย

มาตรา ๑๖ อภิรัฐมนตรีจะพ้นหน้าที่ต่อเมื่อ ลาออก ทุพพลภาพ หรือตาย

มาตรา ๑๗ เมื่อตำแหน่งอภิรัฐมนตรีว่างลงจะได้มี พระบรมราชโองการแต่งตั้งแทน อย่างน้อยผู้ที่ได้รับการแต่ง ตั้งแทน จะต้องมีคุณสมบัติ เป็นผู้รับราชการประจำมา แล้วไม่น้อยกว่า ๒๕ ปี และเคยรับราชการอย่างต่ำตำแหน่ง
