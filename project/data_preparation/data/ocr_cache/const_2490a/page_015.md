ฉบับพิเศษ หน้า ๑๕
ตอนที่ ๔๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๔๙๐

มาตรา ๗๐ ในที่ประชุมแห่งสภาสมาชิกผู้ใดจะกล่าวถ้อยคำใด ๆ ในทางแถลงข้อเท็จจริง หรือแสดงความคิดเห็นหรือออกเสียงลายณะแน่น ย่อมเป็นเอกสิทธิโดยเด็ดขาดผู้ใดจะนำไปเป็นเหตุฟ้องร้องว่ากล่าวสมาชิกผู้นั้นในทางใดมิได้

เอกสิทธินี้คุ้มครองไปถึงผู้พิมพ์โฆษณารายงานการประชุม โดยคำสั่งของสภา และคุ้มครองไปถึงผู้ที่สภาเชิญมาแถลงข้อเท็จจริง หรือแสดงความคิดเห็นในทประชุมด้วย

มาตรา ๕๑ สมัยประชุม ขอวุฒิสภาและสภาผู้แทนย่อมเริ่มต้นและสุดสิ้นลงพร้อมกัน

มาตรา ๕๒ ในปีหนึ่งมีสมัยประชุมของสภาทั้งสองสมัยหนึ่งหรือหลายสมัยแล้วแต่สภาผู้แทนจะกำหนด การประชุมครั้งแรกต้องกำหนดให้สมาชิกได้มาประชุมภายในสามสิบวัน นับแต่วันเลือกตั้ง วันเริ่มสมัยประชุมประจำปีให้สภาผู้แทนเป็นผู้กำหนด

มาตรา ๕๓ สมัยประชุมสามัญสมัยหนึ่ง ๆ มีกำหนดเวลาเก้าสิบวัน แต่พระมหากษัตริย์จะโปรดเกล้าฯ ให้ขยายเวลาออกไป ก็ได้
