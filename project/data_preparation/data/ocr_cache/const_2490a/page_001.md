รัฐธรรมนูญแห่งราชอาณาจักรไทย
(ฉบับชั่วคราว)
ตราไว้ ณ วันที่ ๙ พฤศจิกายน พุทธศักราช ๒๔๙๐
รังสิต กรมาณยนาทนเรนทร
เป็นปีที่ ๒ ในรัชกาลปัจจุบัน

มีพระบรมราชโองการโปรดเกล้า โปรดกระหม่อมให้
ประกาศว่ารัฐธรรมนูญแห่งราชอาณาจักรไทย ที่ตราไว้
