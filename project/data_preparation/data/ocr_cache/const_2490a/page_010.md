ฉบับพิเศษ หน้า ๑๐
ตอนที่ ๕๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๘ พฤศจิกายน ๒๕๕๐

ภายในหนึ่งเดือน รัฐสภาจะต้องปรึกษากันใหม่ ถ้ารัฐสภาลงมติยืนยันตามเดิม ให้นายกรัฐมนตรีนำร่างพระราชบัญญัตินั้นขึ้นทูลเกล้า ฯ เพื่อถวายประกาศใช้ต่อไป

มาตรา ๓๑ ร่างพระราชบัญญัติตั้งหัว นายจะเสนอมาจากคณะรัฐมนตรีหรือจากสมาชิกรัฐสภาก็ได้

มาตรา ๓๒ บุคคลใดจะเป็นสมาชิกวุฒิสภา และสภาผู้แทนขณะเดียวกันไม่ได้

มาตรา ๓๓ วุฒิสภาประกอบด้วยสมาชิกที่พระมหากษัตริย์ทรงเลือกตั้งมีจำนวนเท่าสมาชิกสภาผู้แทน

มาตรา ๓๔ สมาชิกภาพแห่งวุฒิสภา มีกำหนดเวลาคราวละ ๖ ปี จะเพาะเมื่อวาระเริ่มแรกเมื่อครบกำหนด ๓ ปี ให้มีการเปลี่ยนสมาชิกกลิ่งหนึ่งโดยวิธีจับสลาก
