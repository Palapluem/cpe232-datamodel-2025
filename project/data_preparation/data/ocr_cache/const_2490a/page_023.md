ฉบับพิเศษ หน้า ๒๓
ตอนที่ ๕๓ เล่ม ๖๔ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๔๙๐

(๑) การให้ความเห็นชอบในการสืบราชสมบัติ ตามความในมาตรา ๑๒
(๒) การปรึกษาร่างพระราชบัญญัติกันใหม่ตาม ความในมาตรา ๓๐
(๓) พิธีเปิดประชุมรัฐสภาตามความในมาตรา ๕๔
(๔) การลงมติความไว้ใจในคณะรัฐมนตรี ตาม ความในมาตรา ๗๗
(๕) การให้ความยินยอมในการประกาศสงคราม ตามความเห็นชอบในมาตรา ๘๓
(๖) การให้ความเห็นชอบแก่หนังสือสัญญาตาม ความในมาตรา ๘๔
(๗) การตีความในรัฐธรรมนูญตามความในมาตรา ๙๔

มาตรา ๗๑ ให้ประธานวุฒิสภาเป็นประธานของที่ร่วม ประชุมของรัฐสภา และให้ประธานสภาผู้แทนเป็นรอง ประธาน

มาตรา ๗๒ ในการประชุมร่วมกันของรัฐสภา ให้ใช้ข้อ บังคับการประชุมและการปรึกษาของวุฒิสภาโดยอนุโลม
