การเลือกตั้งสมาชิกสภา ร่างรัฐธรรมนูญ ให้กระทำในสมัยประชุมของรัฐสภา - สมัยแรก ภายหลัง การเลือกตั้งสมาชิกสภาผู้แทนตามบทฉะเพาะกาลแห่งรัฐธรรมนูญนี้

มาตรา ๙๕ ตรี ผู้ที่มิใช่สมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน และมีคุณสมบัติดังกำหนดไว้ ในประเภทใดประเภทหนึ่งต่อไปนี้ มีสิทธิสมัครรับเลือกตั้งเป็นสมาชิกสภา ร่างรัฐธรรมนูญ

ประเภท ๑ ผู้มีคุณสมบัติของผู้สมัครรับเลือกตั้งเป็นสมาชิกสภาผู้แทนตามบทฉะเพาะกาลแห่งรัฐธรรมนูญนี้
