ฉบับพิเศษ หน้า ๑๔ เล่ม ๙๓ ตอนที่ ๑๓๕ ราชกิจจานุเบกษา ๒๒ ตุลาคม ๒๕๑๙

เพื่อจะได้ทรงลงพระปรมาภิไธย และเมื่อได้ประกาศรัฐธรรมนูญ นั้นในราชกิจจานุเบกษาแล้วให้ใช้บังคับได้

มาตรา ๒๕ เมื่อไม่มีบทบัญญัติแห่งรัฐธรรมนูญนี้บังคับ แก่กรณีใด ให้วินิจฉัยกรณีนั้นไปตามประเพณีการปกครอง ประเทศไทยในระบอบประชาธิปไตย

ในกรณีมีปัญหาเกี่ยวกับการวินิจฉัยตามความในวรรคหนึ่ง เกิดขึ้นในวงงานของสภาปฏิรูปการปกครองแผ่นดิน หรือเกิดขึ้น โดยคณะรัฐมนตรีขอให้สภาปฏิรูปการปกครองแผ่นดินวินิจฉัย ให้สภาปฏิรูปการปกครองแผ่นดินวินิจฉัยชี้ขาด

มาตรา ๒๖ การแต่งตั้งสมาชิกสภาปฏิรูปการปกครอง แผ่นดิน ให้กระทำให้แล้วเสร็จภายในสามสิบวัน นับแต่วันใช้ รัฐธรรมนูญนี้

ในระหว่างยังไม่มีสภาปฏิรูปการปกครองแผ่นดิน ให้สภา ที่ปรึกษาของนายกรัฐมนตรีทำหน้าที่สภาปฏิรูปการปกครอง แผ่นดิน และเอกสิทธิ์ที่บัญญัติไว้ในมาตรา ๑๓ ให้นำมาใช้ บังคับโดยอนุโลม

มาตรา ๒๗ ให้นายกรัฐมนตรีซึ่งทรงแต่งตั้งและอยู่ใน ตำแหน่งในวันใช้รัฐธรรมนูญนี้เป็นนายกรัฐมนตรีซึ่งพระมหา- กษัตริย์ทรงแต่งตั้งตามมาตรา ๑๖
