ฉบับพิเศษ หน้า ๑๓ เล่ม ๙๓ ตอนที่ ๑๓๕ ราชกิจจานุเบกษา ๒๒ ตุลาคม ๒๕๑๙

(๒) ญัตติขอแก้ไขเพิ่มเติมต้องเสนอเป็นร่างรัฐธรรมนูญแก้ไขเพิ่มเติม และให้สภาปฏิรูปการปกครองแผ่นดินพิจารณาเป็นสามารถ

(๓) การออกเสียงลงคะแนนในวาระที่หนึ่งขั้นรับหลักการให้ใช้วิธีเรียกชื่อและต้องมีคะแนนเสียงเห็นชอบด้วยในการแก้ไขเพิ่มเติมนั้นไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดของสภาปฏิรูปการปกครองแผ่นดิน

(๔) การออกเสียงลงคะแนนในวาระที่สองขั้นพิจารณาลำดับมาตรา ให้ถือเอาเสียงข้างมากเป็นประมาณ

(๕) เมื่อการพิจารณาวาระที่สองเสร็จสิ้นแล้วให้รอไว้ห้าวัน เมื่อพ้นกำหนดนี้แล้ว ให้สภาปฏิรูปการปกครองแผ่นดินพิจารณาในวาระที่สามต่อไป

(๖) การออกเสียงลงคะแนนในวาระที่สามขั้นสุดท้ายให้ใช้วิธีเรียกชื่อและต้องมีคะแนนเสียงเห็นชอบด้วยในการที่จะให้ออกใช้เป็นรัฐธรรมนูญไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดของสภาปฏิรูปการปกครองแผ่นดิน

(๗) เมื่อการลงมติได้เป็นไปตามที่กล่าวแล้ว ให้นำร่างรัฐธรรมนูญแก้ไขเพิ่มเติมขึ้นทูลเกล้า ฯ ถวาย
