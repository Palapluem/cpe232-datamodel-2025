เล่ม ๙๕ ตอนที่ ๑๔๖ ราชกิจจานุเบกษา ๒๒ ธันวาคม ๒๕๒๑

(๑) เงินส่งใช้ต้นเงินกู้
(๒) ดอกเบี้ยเงินกู้
(๓) เงินที่กำหนดให้จ่ายตามกฎหมาย

มาตรา ๑๓๔ การจ่ายเงินแผ่นดิน จะกระทำได้ก็เฉพาะที่ได้อนุญาตไว้ในกฎหมายว่าด้วยงบประมาณรายจ่าย กฎหมายว่าด้วยวิธีการงบประมาณ หรือกฎหมายเกี่ยวด้วยการโอนงบประมาณ หรือกฎหมายว่าด้วยเงินคงคลัง เว้นแต่ในกรณีจำเป็นรีบด่วนจะจ่ายไปก่อนก็ได้ แต่ต้องเป็นไปตามหลักเกณฑ์และวิธีการที่กฎหมายบัญญัติ ในกรณีเช่นว่านี้ ต้องตั้งงบประมาณรายจ่ายชดใช้ในพระราชบัญญัติโอนงบประมาณรายจ่าย หรือพระราชบัญญัติงบประมาณรายจ่ายเพิ่มเติม หรือพระราชบัญญัติงบประมาณรายจ่ายประจำปีงบประมาณถัดไป

มาตรา ๑๓๕ วุฒิสภาและสภาผู้แทนราษฎรมีอำนาจควบคุมการบริหารราชการแผ่นดินโดยบทบัญญัติแห่งรัฐธรรมนูญนี้

มาตรา ๑๓๖ ในที่ประชุมวุฒิสภาหรือสภาผู้แทนราษฎร สมาชิกทุกคนมีสิทธิตั้งกระทู้ถามรัฐมนตรีในเรื่องใดเกี่ยวกับงานในหน้าที่ได้ แต่รัฐมนตรีย่อมมีสิทธิที่จะไม่ตอบเมื่อคณะรัฐมนตรีเห็นว่าเรื่องนั้นยังไม่ควรเปิดเผย เพราะเกี่ยวกับความปลอดภัยหรือประโยชน์สำคัญของแผ่นดิน

มาตรา ๑๓๗ สภาษิกสภาผู้แทนราษฎรจำนวนไม่น้อยกว่าหนึ่งในห้าของจำนวนสมาชิกทั้งหมดของสภาผู้แทนราษฎร มีสิทธิเข้าชื่อเสนอญัตติขอเปิดอภิปรายทั่วไปเพื่อลงมติไม่ไว้วางใจรัฐมนตรีเป็นรายบุคคล หรือทั้งคณะ
