บททั่วไป

มาตรา ๗๔ รัฐสภาประกอบด้วยวุฒิสภาและสภาผู้แทนราษฎร
รัฐสภาจะประชุมร่วมกันหรือแยกกัน ย่อมเป็นไปตามบทบัญญัติแห่งรัฐธรรมนูญนี้

มาตรา ๗๕ ประธานวุฒิสภาเป็นประธานรัฐสภา ประธานสภาผู้แทนราษฎรเป็นรองประธานรัฐสภา
ประธานรัฐสภามีอำนาจหน้าที่ดำเนินกิจการของรัฐสภาในกรณีประชุมร่วมกันให้เป็นไปตามระเบียบ และมีอำนาจหน้าที่อื่นตามที่บัญญัติในรัฐธรรมนูญนี้
ในกรณีที่ประธานรัฐสภาไม่อยู่หรือไม่สามารถปฏิบัติหน้าที่ได้ ให้รองประธานรัฐสภาทำหน้าที่แทน

มาตรา ๗๖ ร่างพระราชบัญญัติจะตราขึ้นเป็นกฎหมายได้ก็แต่ โดยคำแนะนำและยินยอมของรัฐสภา

มาตรา ๗๗ ร่างพระราชบัญญัติที่ได้รับความเห็นชอบของรัฐสภาแล้ว ให้นายกรัฐมนตรีนำขึ้นทูลเกล้า ฯ ถวายเพื่อพระมหากษัตริย์ทรงลงพระปรมาภิไธย และเมื่อได้ประกาศในราชกิจจานุเบกษาแล้ว ให้ใช้บังคับเป็นกฎหมายได้
