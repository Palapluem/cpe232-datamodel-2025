สยามินทราธิราช บรมนาถบพิตร
ตราไว้ ณ วันที่ ๒๒ ธันวาคม พุทธศักราช ๒๕๒๑
เป็นปีที่ ๓๓ ในรัชกาลปัจจุบัน

ศุภมัสตุ พระพุทธศาสนกาลเป็นอดีตภาค ๒๕๒๑ พรรษา ปัจจุบัน
สมัย จันทรคตินิยม เอฬกสมพัตสร มิคสิรมาส กาฬปักษ์ อัฏฐมิติถี
สุริยคติกาล ธันวาคมมาส พาวีสติมสุรทิน ศุกรวาร โดยกาลบริเฉท

พระบาทสมเด็จพระปรมินทรมหาภูมิพลอดุลยเดช มหิตลาธิเบศร
รามาธิบดี จักรีนฤบดินทร สยามินทราธิราช บรมนาถบพิตร ทรงพระ
กรุณาโปรดเกล้าโปรดกระหม่อมให้ประกาศว่า สภานิติบัญญัติแห่งชาติ
ได้นำความกราบบังคมทูลว่า นับแต่เมื่อสมเด็จพระบรมปิตุลาธิราช
พระบาทสมเด็จพระปรมินทรมหาประชาธิปก พระปกเกล้าเจ้าอยู่หัว ได้
