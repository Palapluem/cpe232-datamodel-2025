เล่ม ๙๕ ตอนที่ ๑๔๖ ราชกิจจานุเบกษา ๒๒ ธันวาคม ๒๕๒๑

การจำกัดเสรีภาพเช่นว่านี้ จะกระทำมิได้ เว้นแต่โดยอาศัยอำนาจตามบทบัญญัติแห่งกฎหมายเฉพาะเพื่อรักษาความมั่นคงของรัฐ หรือเพื่อคุ้มครองสิทธิเสรีภาพ เกียรติยศหรือชื่อเสียงของบุคคลอื่น หรือเพื่อรักษาความสงบเรียบร้อยหรือศีลธรรมอันดีของประชาชน หรือเพื่อบ้องกันหรือระงับความเสื่อมทรามทางจิตใจหรือสุขภาพของประชาชน

เจ้าของกิจการหนังสือพิมพ์ต้องเป็นบุคคลสัญชาติไทย ทั้งนี้ตามเงื่อนไขที่กฎหมายบัญญัติ

การให้เงินหรือทรัพย์สินอย่างอื่นอุดหนุนหนังสือพิมพ์ของเอกชน รัฐจะกระทำมิได้

มาตรา ๓๕ บุคคลย่อมมีเสรีภาพในการศึกษาอบรม เมื่อไม่ขัดต่อหน้าที่ของพลเมืองตามรัฐธรรมนูญ และไม่ขัดต่อกฎหมายว่าด้วยการศึกษาภาคบังคับและกฎหมายว่าด้วยการจัดตั้งสถานศึกษา

มาตรา ๓๖ บุคคลย่อมมีเสรีภาพในการชุมนุมโดยสงบและปราศจากอาวุธ
