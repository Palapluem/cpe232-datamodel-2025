มาตรา ๑๑๐ ประธานวุฒิสภาและประธานสภาผู้แทนราษฎร มีอำนาจหน้าที่ดำเนินกิจการของสภานั้น ๆ ให้เป็นไปตามระเบียบ รองประธานมีอำนาจหน้าที่กำกิจการแทนประธานเมื่อประธานไม่อยู่หรือไม่สามารถปฏิบัติหน้าที่ได้
มาตรา ๑๑๑ เมื่อประธานและรองประธานวุฒิสภาหรือประธานและรองประธานสภาผู้แทนราษฎรไม่อยู่ในที่ประชุม ให้สมาชิกแห่งสภานั้น ๆ เลือกตั้งกันขึ้นเองเป็นประธานในคราวประชุมนั้น
