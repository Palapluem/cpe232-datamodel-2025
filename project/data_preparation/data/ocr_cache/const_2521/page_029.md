ฉบับพิเศษ หน้า ๒๙
เล่ม ๙๕ ตอนที่ ๑๔๖ ราชกิจจานุเบกษา ๒๒ ธันวาคม ๒๕๒๑

ท้องถิ่น หรือพนักงานส่วนท้องถิ่น ทั้งนี้ นอกจากตำแหน่งรัฐมนตรีหรือข้าราชการการเมืองอื่น

(๒) ไม่รับสัมปทานจากรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจ หรือเป็นคู่สัญญากับรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจอันมีลักษณะเป็นการผูกขาดตัดตอน ทั้งนี้ ไม่ว่าโดยทางตรงหรือทางอ้อม

(๓) ไม่รับเงินหรือประโยชน์ใด ๆ จากหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจเป็นพิเศษ นอกเหนือไปจากที่หน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจปฏิบัติกับบุคคลอื่น ๆ ในธุรกิจ การงานตามปกติ

ความใน (๒) มิให้ใช้บังคับในกรณีที่สมาชิกสภาผู้แทนราษฎรได้รับสัมปทาน หรือเป็นคู่สัญญาอยู่ก่อนได้รับเลือกตั้ง

บทบัญญัติมาตรานี้มิให้ใช้บังคับในกรณีที่สมาชิกสภาผู้แทนราษฎรรับเบี้ยหวัด บำเหน็จ บำนาญ หรือเงินปีพระบรมวงศานุวงศ์ หรือเงินอื่นใดในลักษณะเดียวกัน และมิให้ใช้บังคับในกรณีที่สมาชิกสภาผู้แทนราษฎรรับหรือดำรงตำแหน่งกรรมาธิการของรัฐสภา หรือสภาผู้แทนราษฎร หรือกรรมการที่ได้รับแต่งตั้งในฐานะเป็นผู้ทรงคุณวุฒิตามบทบัญญัติแห่งกฎหมาย หรือกรรมการที่ได้รับแต่งตั้งในการบริหารราชการแผ่นดินในกรณีที่ดำรงตำแหน่งข้าราชการการเมือง

มาตรา ๙๘ ภายใต้บังคับบทบัญญัติแห่งรัฐธรรมนูญนี้ หลักเกณฑ์และวิธีการเลือกตั้งให้เป็นไปตามกฎหมายว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราษฎร
