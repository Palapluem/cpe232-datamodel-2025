ฉบับพิเศษ หน้า ๓๓
เล่ม ๙๕ ตอนที่ ๑๔๖ ราชกิจจานุเบกษา ๒๒ ธันวาคม ๒๕๒๑

ให้ประธานสภาผู้แทนราษฎรเป็นผู้ลงนามรับสนองพระบรมราชโองการแต่งตั้งผู้นำฝ่ายค้านในสภาผู้แทนราษฎร
ผู้นำฝ่ายค้านในสภาผู้แทนราษฎรอย่อมพ้นจากตำแหน่งเมื่อขาดคุณสมบัติดังกล่าวในวรรคหนึ่ง และให้นำบทบัญญัติมาตรา ๑๐๙ มาใช้บังคับโดยอนุโลม ในกรณีเช่นนี้ พระมหากษัตริย์จะได้ทรงแต่งตั้งผู้นำฝ่ายค้านในสภาผู้แทนราษฎรแทนตำแหน่งที่ว่าง

ส่วนที่ ๔
บทที่ใช้แก่สภาทั้งสอง

มาตรา ๑๐๖ สภาผู้แทนราษฎรและสมาชิกสภาผู้แทนราษฎร ย่อมเป็นผู้แทนปวงชนชาวไทย
มาตรา ๑๐๗ ก่อนเข้ารับหน้าที่ สภาผู้แทนราษฎรและสมาชิกสภาผู้แทนราษฎรอ้างปฏิญาณตนในที่ประชุมแห่งสภาที่ตนเป็นสมาชิก ด้วยถ้อยคำดังต่อไปนี้
"ข้าพเจ้า (ชื่อผู้ปฏิญาณ) ขอปฏิญาณว่า ข้าพเจ้าจะปฏิบัติหน้าที่ด้วยความซื่อสัตย์สุจริต เพื่อประโยชน์ส่วนรวมของปวงชนชาวไทย ทั้งจะรักษาไว้และปฏิบัติตามซึ่งรัฐธรรมนูญแห่งราชอาณาจักรไทยทุกประการ"
มาตรา ๑๐๘ วุฒิสภาและสภาผู้แทนราษฎรแต่ละสภา มีประธานสภาคนหนึ่งและรองประธานคนหนึ่งหรือสองคน ซึ่งพระมหากษัตริย์ทรงแต่งตั้งจากสมาชิกแห่งสภานั้น ๆ ตามมติของสภา
