ฉบับพิเศษ หน้า ๖ เล่ม ๙๕ ตอนที่ ๑๔๖ ราชกิจจานุเบกษา ๒๒ ธันวาคม ๒๕๒๑

ให้ประธานองคมนตรีเป็นผู้ลงนามรับสนองพระบรมราชโองการ แต่งตั้งองคมนตรีอื่นหรือให้องคมนตรีอื่นพ้นจากตำแหน่ง

มาตรา ๑๒ องคมนตรีต้องไม่เป็นสมาชิกวุฒิสภา สมาชิกสภา ผู้แทนราษฎร ข้าราชการซึ่งมีตำแหน่งหรือเงินเดือนประจำ พนักงาน รัฐวิสาหกิจ หรือสมาชิกหรือเจ้าหน้าที่ในพรรคการเมือง และต้องไม่แสดง การฝึกใฝ่ในพรรคการเมืองใด ๆ

มาตรา ๑๓ ก่อนเข้ารับหน้าที่ องคมนตรีต้องถวายสัตย์ปฏิญาณ ต่อพระมหากษัตริย์ด้วยถ้อยคำดังต่อไปนี้

"ข้าพระพุทธเจ้า (ชื่อผู้ปฏิญาณ) ขอถวายสัตย์ปฏิญาณว่า ข้าพระพุทธเจ้าจะจงรักภักดีต่อพระมหากษัตริย์ และจะปฏิบัติหน้าที่ด้วย ความซื่อสัตย์สุจริต เพื่อประโยชน์ของประเทศและประชาชน ทั้งจะ รักษาไว้และปฏิบัติตามซึ่งรัฐธรรมนูญแห่งราชอาณาจักรไทยทุกประการ"

มาตรา ๑๔ องคมนตรีพ้นจากตำแหน่งเมื่อตาย ลาออก หรือ มีพระบรมราชโองการให้พ้นจากตำแหน่ง

มาตรา ๑๕ การแต่งตั้งและการให้ข้าราชการในพระองค์และ สมุหราชองครักษ์พ้นจากตำแหน่ง ให้เป็นไปตามพระราชอธยาศัย

มาตรา ๑๖ ในเมื่อพระมหากษัตริย์จะไม่ประทับอยู่ในราชอาณา จักรหรือจะทรงบริหารพระราชภาระไม่ได้ด้วยเหตุใดก็ตาม จะได้ทรง แต่งตั้งผู้ใดผู้หนึ่งด้วยความเห็นชอบของรัฐสภาเป็นผู้สำเร็จราชการแทน พระองค์ และให้ประธานรัฐสภาเป็นผู้ลงนามรับสนองพระบรมราชโองการ
