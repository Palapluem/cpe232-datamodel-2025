มาตรา ๑๙๗ ให้คณะองคมนตรีที่ดำรงตำแหน่งอยู่ก่อนวันใช้รัฐธรรมนูญนี้ เป็นคณะองคมนตรีตามบทบัญญัติแห่งรัฐธรรมนูญนี้

เมื่อได้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎรตามมาตรา ๒๐๒ แล้ว ให้คณะรัฐมนตรีตามวรรคหนึ่งพ้นจากตำแหน่ง แต่ต้องอยู่ในตำแหน่งเพื่อดำเนินงานไปจนกว่าคณะรัฐมนตรีที่ตั้งขึ้นใหม่จะเข้ารับหน้าที่
