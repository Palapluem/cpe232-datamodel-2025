ฉบับพิเศษ หน้า ๓ เล่ม ๗๖ ตอนที่ ๑๗ ราชกิจจานุเบกษา ๒๘ มกราคม ๒๕๐๒

บรมราชโองการโปรดเกล้าโปรดกระหม่อมให้ใช้บทบัญญัติต่อไปนี้เป็นธรรมนูญการปกครองราชอาณาจักร จนกว่าจะได้ประกาศใช้รัฐธรรมนูญซึ่งสภาร่างรัฐธรรมนูญจะได้จัดร่างขึ้น มาตรา ๑ อำนาจอธิปไตยมาจากปวงชนชาวไทย

มาตรา ๒ ประเทศไทยเป็นราชอาณาจักรอันหนึ่งอันเดียว จะแบ่งแยกมิได้ พระมหากษัตริย์ทรงเป็นพระประมุข และดำรงตำแหน่งจอมทัพไทย

มาตรา ๓ องค์พระมหากษัตริย์ดำรงอยู่ในฐานะอันเป็นที่เคารพสักการ ผู้ใดจะละเมิดมิได้

มาตรา ๔ ให้มีคณะองคมนตรีคณะหนึ่ง มีจำนวนไม่เกินเก้าคน การแต่งตั้งและการพ้นจากตำแหน่งองคมนตรีให้เป็นไปตามพระราชอัธยาศัย

มาตรา ๕ พระมหากษัตริย์ทรงตราพระราชบัญญัติใช้บังคับโดยคำแนะนำและยินยอมของรัฐสภา

คณะรัฐมนตรีใช้อำนาจบบริหารและศาลใช้อำนาจตุลาการทั้งนี้ในพระปรมาภิไธยพระมหากษัตริย์

มาตรา ๖ ให้มีสภาร่างรัฐธรรมนูญมีหน้าที่ร่างรัฐธรรมนูญ และให้มีฐานะเป็นรัฐสภา ทำหน้าที่นิติบัญญัติด้วย
