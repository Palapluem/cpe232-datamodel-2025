หมวด ๗
การใช้รัฐธรรมนูญและบทฉะเพาะกาล

มาตรา ๖๔ ภายในบังคับแห่งบทบัญญัติหมวดนี้ ให้ ใช้รัฐธรรมนูญนี้ตั้งแต่วันประกาศเป็นต้นไป

มาตรา ๖๕ เมื่อราษฎรผู้มีสิทธิออกเสียงเลือกตั้งสมาชิก สภาผู้แทนราษฎรตามบทบัญญัติแห่งรัฐธรรมนูญนี้ ยังมี การศึกษาไม่จบประถมศึกษาสามัญมากกว่ากึ่งจำนวนทั้งหมด และอย่างช้าต้องไม่เกินกว่าสิบปี นับแต่วันใช้พระราชบัญญัติ ธรรมนูญการปกครองแผ่นดินสยามชั่วคราว พ.ศ. ๒๔๗๕ สภาผู้แทนราษฎรประกอบด้วยสมาชิก ๒ ประเภทมีจำนวน เท่ากัน
(๑) สมาชิกประเภทที่ ๑ ได้แก่ผู้ที่ราษฎรเลือกตั้งขึ้น ตามเงื่อนไขในบทบัญญัติมาตรา ๑๖,๑๗
