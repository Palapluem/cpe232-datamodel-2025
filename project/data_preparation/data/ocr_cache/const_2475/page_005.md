วันที่ ๑๐ ธันวาคม ๒๔๗๕ ราชกิจจานุเบกษา เล่ม ๔๙ หน้า ๕๓๓

เมื่อและทรงพระราชวิจารณ์ ถี่ถ้วนทั่วกระบวนความแล้ว ทรง
พระราชดำริเห็นสมควรพระราชทานพระบรมราชานุมัติ

จึงมีพระบรมราชโองการดำรัสเหนือเกล้าเหนือกระหม่อม
สั่งให้ตรารัฐธรรมนูญแห่งราชอาณาจักรสยาม ประสิทธิ์
ประสาทประกาศพระราชทานแก่ประชากรของพระองค์ ให้
ดำรงอิสสราธิปไตยโดยบริบูรณ์ ตั้งแต่วันนี้เป็นต้นไป

ขอให้รัฐธรรมนูญแห่งราชอาณาจักรของเรานี้ จงเป็น
หลักที่สถาพรสถิตประดิษฐานสมรรถภาพอันประเสริฐ เป็น
บ่อเกิดความผาสุกสันติคุณวิบุลราศีแก่อาณาประชาชนตลอด
จำเนียรกาลประวัติ นำประเทศสยามบรรลุสรรพพิพัฒนชัย
มงคล อเนกศุภผลสกลเกียรติยศมโหฬาร ขอให้พระบรม
ราชวงศานุวงศ์ และข้าราชการทั้งทหารพลเรือนทวยอาณา
ประชาราษฎร จงมีความสมัครสโมสรเป็นเอกฉันท์ในอันจะ
รักษาปฏิบัติรัฐธรรมนูญแห่งราชอาณาจักรสยามนี้ ให้ยืนยง
อยู่คู่กับสยามรัฐราชสีมา ตราบเท่ากัลปาวสานสมดังพระ
บรมราชประณิธาน ทุกประการเทอญ
