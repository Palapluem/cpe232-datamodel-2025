เล่ม ๔๙ หน้า ๕๓๘ ราชกิจจานุเบกษา วันที่ ๑๐ ธันวาคม ๒๔๗๕

มาตรา ๒๑ สมาชิกภาพแห่งสภาผู้แทนราษฎรสิ้นสุดลง เมื่อ
(๑) ถึงคราวออกตามวาระ หรือยุบสภา
(๒) ตาย
(๓) ลาออก
(๔) ขาดคุณสมบัติของผู้สมัครรับเลือกตั้งตามกฎหมายว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราษฎร
(๕) สภาผู้แทนราษฎรวินิจฉัยให้ออกจากตำแหน่งโดยเห็นว่ามีความประพฤติในทางจะนำมาซึ่งความเสื่อมเสียแก่สภา มติในข้อนี้ต้องมีเสียงไม่ต่ำกว่าสองในสามของจำนวนสมาชิกที่มาประชุม

มาตรา ๒๒ พระมหากษัตริย์ทรงตั้งสมาชิกในสภาผู้แทนราษฎรตามมติของสภา ให้เป็นประธานแห่งสภาหนึ่งนายเป็นรองประธานนายหนึ่งหรือหลายนายก็ได้

มาตรา ๒๓ ประธานแห่งสภามีหน้าที่ดำเนินกิจการของสภาให้เป็นไปตามระเบียบ รองประธานมีหน้าที่กระทำกิจการแทนประธานในเมื่อประธานไม่อยู่หรือไม่สามารถปฏิบัติหน้าที่ได้
