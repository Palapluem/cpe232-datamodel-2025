เล่ม ๕๙ หน้า ๕๔๖ ราชกิจจานุเบกษา วันที่ ๑๐ ธันวาคม ๒๔๗๕

มาตรา ๔๙ การตั้งสมาชิกสภาผู้แทนราษฎรเป็นรัฐมนตรีนั้น ไม่ทำให้ผู้ใดได้รับตั้งจำต้องลาออกจากสมาชิกภาพ

มาตรา ๕๐ ในการบริหารราชการแผ่นดินคณะรัฐมนตรีต้องปฏิบัติหน้าที่ด้วยความไว้ใจของสภาผู้แทนราษฎร

รัฐมนตรีผู้ใดรับแต่งตั้งให้บัญชาการกระทรวงทะบวงการต้องรับผิดชอบในหน้าที่ของตนต่อสภาผู้แทนราษฎรในทางรัฐธรรมนูญและรัฐมนตรีทุกคนจะได้รับแต่งตั้งให้บัญชาการกระทรวงทะบวงการหรือไม่ก็ตาม ต้องรับผิดชอบร่วมกันในนโยบายทั่วไปของรัฐบาล

มาตรา ๕๑ รัฐมนตรีทั้งคณะต้องออกจากตำแหน่งเมื่อสภาผู้แทนราษฎรลงมติไม่ไว้ใจในคณะ หรือเมื่อสภาผู้แทนราษฎรชุดที่ให้ความไว้ใจแก่คณะรัฐมนตรีในขณะเข้ารับหน้าที่นั้นสิ้นสุดลง ในกรณีทั้งสองนี้ ท่านว่าคณะรัฐมนตรีที่ออกนั้น ต้องอยู่ในตำแหน่ง เพื่อดำเนินการไปจนกว่าคณะรัฐมนตรีที่ตั้งขึ้นใหม่จะเข้ารับหน้าที่
