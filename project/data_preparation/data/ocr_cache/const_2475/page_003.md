วันที่ ๑๐ ธันวาคม ๒๔๗๕ ราชกิจจานุเบกษา เล่ม ๔๙ หน้า ๕๓๑

เสด็จออกณพระที่นั่งอนันตสมาคม ท่ามกลางอุดมสันนิบาต พระบรมราชวังศานุวงศ์ และทูตานุทูตผู้แทนมานาประเทศ สมาชิกสภาผู้แทนราษฎร เสนามาตายราชบริพาร เฝ้าเบื้องบาทบงกชพรั่งพร้อมกันโดยอนุกรม

ทรงพระกรุณาโปรดเกล้าโปรดกระหม่อม ให้ประกาศความพระราชปรารภว่า ข้าราชการทหารพลเรือน และอาณาประชาราษฎรของพระองค์ ได้นำความขึ้นกราบบังคมทูลพระกรุณา ขอพระราชทานรัฐธรรมนูญเพื่อให้สยามราชอาณาจักรได้มีการปกครองตามวิสัยอารยประเทศในสมัยปัจจุบัน

ทรงพระราชดำริเห็นว่า สมเด็จพระเจ้าแผ่นดินในพระบรมราชจักรีวงศ์ ได้เสด็จเถลิงถัวัลยราชย์ผ่านสยามพิภพทรงดำเนินพระราชโอบายปกครองราชอาณาจักร ด้วยวิธีสมบูรณญาสิทธิราชภายในทศพิธราชธรรมจรรยา ทรงทำนุบำรุงประเทศให้รุ่งเรืองไพบูลย์สืบมาครบ ๑๕๐ ปีบริบูรณ์ประชาชนชาวสยามได้รับพระบรมราชบริหารในวิถีความเจริญมานาประการโดยลำดับ จนบัดนี้มีการศึกษาสูงขึ้นแล้ว มีข้าราชการประกอบด้วยวุฒิปรีชาในรัฐาภิปาลโนบายสามารถนำประเทศชาติของตน ในอันที่จะก้าวหน้าไปสู่
