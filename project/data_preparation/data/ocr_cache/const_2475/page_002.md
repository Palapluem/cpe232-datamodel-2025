เล่ม ๔๙ หน้า ๕๓๐ ราชกิจจานุเบกษา วันที่ ๑๐ ธันวาคม ๒๔๗๕

พระบาทสมเด็จพระปรมินทรมหาประชาธิปก มหันตเตชน ดิลกรามาธิบดี เทพยปรียมหาราชรวิวงศ อสัมภินพงศพีระ กษัตร บุรุษรัตนราชนิกโรดม จาตุรันตบรมมหาจักรพรรดิราช สังกาศ อุภโตสุชาตสำคฺขทธเคราหณี จักรีบรูมนาถ จุฬาลงกรณราชวรางกูร มหามกุฏวงศ์วีรสูรชิษฐ ราชธรรมทศพิธ อุต์กฤษฎนิบุณ อดุลยกฤษฎาภินีร์หาร บูรพาธิการสุสาธิต ธันยลักษณวิจิตรเสากายสรรพางค์ มหาชโนตมางคมานท สนธิมตสมันตสมาคม บรมราชสมภาร ทิพยเทพาวตาร ไพศาลเกียรติคุณ อดุลยศักดิเดช สรรพเทเวศปริยานุรักษ มงคลลัดเนมาหวัย สุโขทัยธรรมราชา อภิเนาวศิลปศึกษา เดชนาวุธ วิชัยยุทธศาสตรโกศล วิมลนรรยพินิต สุจริตสมา- จาร ภัทรภิชญานประดิภานสุนทร ประวรศาสนโนปสดมภก มูลมุขมาตยวรนายกมหาเสนานี สราชนาวีพยุหโยธโพยมจร บรมเชษฐโสทรสมมต เอกราชยยศสถิคมบรมราชสมบัติ นพปฎลเศวตฉัตราดิฉัตร ศรีรัตโนปลักษณ มหาบรมราชา- ภิเษกาภิษกต์ สรรพทศทิควิชิตเดโชไชย สกลมไหศวรยมหา สวามินทร มเหศวรมหินทรมหารามาธิราชวโรดม บรมนาถ ชาติอาชันยาศรัย พุทธาทิไตรรัตนศรณารักษ วิศิษฏศักตอัคร นเรศวราธิบดี เมตตากรุณาศีตลหฤทัย อโนปไมยบุญยการ สกลไพศาลมุหารัษฎราธิบดินทร ปรมินทรธรรมิกมหาราชา- ธิราช บรมนาถบพิตร พระปกเกล้าเจ้าอยู่หัว
