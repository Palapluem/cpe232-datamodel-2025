วันที่ ๑๐ ธันวาคม ๒๔๗๕ ราชกิจจานุเบกษา เล่ม ๔๙ หน้า ๕๔๗

(๔) สภาผู้แทนราษฎรลงมติไม่ไว้ใจ

มาตรา ๕๒ ในเหตุฉุกเฉินซึ่งจะเรียกประชุมสภาผู้แทนราษฎรให้ทันท่วงทีมิได้ พระมหากษัตริย์จะทรงตราพระราชกำหนดให้ใช้นังคับดั่งเช่นพระราชบัญญัติก็ได้

ในคราวประชุมสภาผู้แทนราษฎรต่อไป ท่านให้นำพระราชกำหนดนั้นเสนอต่อสภาเพื่ออนุมัติ ถ้าสภากอนุมัติแล้ว พระราชกำหนดนั้นก็เป็นพระราชบัญญัติต่อไป ถ้าสภาไม่อนุมัติไซร้ พระราชกำหนดนั้นก็เป็นอันตกไป แต่ทั้งนี้ไม่กระทบถึงกิจการที่ได้เป็นไปในระหว่างที่ใช้พระราชกำหนดนั้น

คำอนุมัติและไม่อนุมัติของสภาที่กล่าวนี้ ท่านว่าให้ทำเป็นพระราชบัญญัติ

มาตรา ๕๓ พระมหากษัตริย์ทรงประกาศใช้กฎอัยยการศึกตามลักษณะและวิธีการในพระราชบัญญัติกฎอัยยการศึก

มาตรา ๕๔ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจในการประกาศสงคราม ทำหนังสือสัญญาสันติภาพสงบศึก และทำหนังสือสัญญาอื่น ๆ กับนานาประเทศ

การประกาศสงครามนั้น จะทรงทำต่อเมื่อไม่ขัดแก่บทบัญญัติแห่งกติกาสันนิบาตชาติ
