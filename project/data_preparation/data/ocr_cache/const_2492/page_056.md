บริหารราชการแผ่นดิน

ญัตติตั้งกล่าวในวรรคก่อน ถ้าเป็นของสมาชิกแห่ง
สภาใดก็ให้ยื่นต่อประธานแห่งสภานั้น และให้ประธาน
แห่งสภาที่ได้รับญัตติแจ้งไปยังนายกรัฐมนตรี เพื่อกำหนด
เวลาสำหรับการเปิดอภิปรายทั่วไป ซึ่งต้องไม่ช้ากว่าสามสิบ
วันนับแต่วันที่นายกรัฐมนตรีได้รับแจ้ง แต่คณะรัฐมนตรี
ย่อมมีสิทธิที่จะขอให้ระงับการเปิดอภิปรายทั่วไป นั้นเสียได้
เมื่อเห็นว่าเป็นเรื่องที่ยังไม่ควรเปิดเผย เพราะเกี่ยวกับความ
ปลอดภัยหรือประโยชน์สำคัญของแผ่นดิน

ในการเปิดอภิปรายทั่วไปตามมาตรานี้ สภาจะลงมติ
ในปัญหาที่อภิปรายมิได้

ของจำนวนสมาชิกทั้งหมด มีสิทธิเข้าชื่อเสนอญัตติขอ
เปิดอภิปรายทั่วไปเพื่อลงมติไม่ไว้วางใจรัฐมนตรีเป็นรายตัว
