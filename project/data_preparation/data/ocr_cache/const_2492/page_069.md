ฉะบับพิเศษ หน้า ๖๙
ตอนที่ ๑๘ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

มาตรา ๑๖๒ บรรดาศาลทั้งหลายจะตั้งขึ้นได้ก็แต่โดย พระราชบัญญัติ

มาตรา ๑๖๓ การตั้งศาลขึ้นใหม่ เพื่อพิจารณาพิพากษา คดีใดคดีหนึ่งหรือที่มีข้อหาฐานใดฐานหนึ่งโดยฉะเพาะ แทน ศาลธรรมดาที่มีอยู่ตามกฎหมายสำหรับพิจารณาพิพากษาคดี นั้น จะกระทำมิได้

มาตรา ๑๖๔ การบัญญัติกฎหมายให้มีผลเป็นการ เปลี่ยนแปลงหรือแก้ไขเพิ่มเติมกฎหมายว่าด้วยธรรมนูญศาล หรือวิธีพิจารณา เพื่อใช้แก่คดีใดคดีหนึ่งโดยฉะเพาะ จะ กระทำมิได้

มาตรา ๑๖๕ ผู้พิพากษามีอิสระในการพิจารณา พิพากษาอรวรคคดีให้เป็นไปตามกฎหมาย

มาตรา ๑๖๖ พระมหากษัตริย์ทรงแต่งตั้ง ย้าย และ ถอดถอนผู้พิพากษา

มาตรา ๑๖๗ การแต่งตั้ง การย้าย และการถอด ถอนผู้พิพากษาจะต้องได้รับความเห็นชอบของคณะกรรมการ
