ฉบับพิเศษ หน้า ๕๓
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

ร่างพระราชบัญญัติได้ และเอกสิทธิ์ที่บัญญัติไว้ในมาตรา ๑๐๙ นั้น ให้คุ้มครองถึงบุคคลผู้กระทำหน้าที่ตามมาตรานี้ด้วย

การประชุมคณะกรรมาธิการร่วมกัน ต้องมีกรรมาธิการประชุมไม่ต่ำกว่ากึ่งจำนวนกรรมาธิการทั้งหมด จึงจะเป็นองค์ประชุม และให้นำข้อบังคับการประชุมปรึกษาของวุฒิสภาในส่วนที่เกี่ยวกับกรรมาธิการมาใช้บังคับโดยอนุโลม

มาตรา ๑๒๔ ร่างพระราชบัญญัติที่ต้องยับยั้งไว้โดยบทบัญญัติมาตรา ๒๒๓ นั้น เมื่อเวลาหนึ่งปีได้ล่วงพ้นไป นับแต่วันที่วุฒิสภาส่งร่างพระราชบัญญัติกลับคืนมายังสภาผู้แทนสภาผู้แทนอาจยกร่างพระราชบัญญัตินั้น ขึ้น พิจารณาใหม่ได้ ในกรณีเช่นว่านี้ ถ้าหากสภาผู้แทนลงมติยืนยันร่างเดิมหรือร่างที่คณะกรรมาธิการร่วมกันพิจารณาด้วยคะแนนเสียงมากกว่ากึ่งจำนวนสมาชิกทั้งหมดของสภาแล้ว ก็ให้ถือว่าร่างพระราชบัญญัตินั้นเป็นอันได้รับความเห็นชอบของรัฐสภา และให้ดำเนินการต่อไปตามความในมาตรา ๗๖

ถ้าร่างพระราชบัญญัติที่ต้องยับยั้งไว้เป็นพระราชบัญญัติเกี่ยวด้วยการเงิน สภาผู้แทนอาจยกร่างพระราชบัญญัตินั้น
