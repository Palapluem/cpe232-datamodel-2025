ฉบับพิเศษ หน้า ๑๘
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

ค้นเคยสถานก็ดี จะกระทำได้ก็แต่โดยอาศัยอำนาจตามบทบัญญัติแห่งกฎหมาย

มาตรา ๓๔ สิทธิของบุคคลในทรัพย์สินย่อมได้รับความคุ้มครอง ขอบเขตต์และการจำกัดสิทธิเช่นว่านี้ย่อมเป็นไปตามบทบัญญัติแห่งกฎหมาย

การสืบมฤตกย่อมได้รับความคุ้มครอง สิทธิของบุคคลในการสืบมฤตกย่อมเป็นไปตามบทบัญญัติแห่งกฎหมาย

การเวนคืนอสังหาริมทรัพย์ จะกระทำได้ก็แต่โดยอาศัยอำนาจตามบทบัญญัติแห่งกฎหมายฉะเพาะเพื่อการอันเป็นสาธารณูปโภค หรือการอันจำเป็นในการป้องกันประเทศ โดยตรง หรือการได้มาซึ่งทรัพยากรธรรมชาติ และต้องชดใช้ค่าทำขวัญอันเป็นธรรมแก่เจ้าของ ตลอดจนผู้ทรงสิทธิตามที่ระบุไว้ในกฎหมายว่าด้วยการเวนคืนอสังหาริมทรัพย์บรรดาที่ได้รับความเสียหายในการเวนคืนนั้นด้วย

การที่เจ้าหน้าที่ของรัฐจะเข้าใช้หรือครอบครองอสังหาริมทรัพย์ของบุคคลก็ดี การโอนกรรมสิทธิ์ในอสังหาริมทรัพย์ของบุคคลมาเป็นของรัฐก็ดี ถ้ามิใช่ด้วยความยินยอมของ
