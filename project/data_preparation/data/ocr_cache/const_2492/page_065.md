ฉบับพิเศษ หน้า ๖๕
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

(๔) ต้องคำพิพากษาโทษจำคุก
(๕) กระทำการที่ต้องห้ามตามมาตรา ๑๔๓
(๖) สภาผู้แทนลงมติไม่ไว้วางใจตามมาตรา ๑๓๑

มาตรา ๑๕๐ ในเหตุฉุกเฉินที่มีความจำเป็นรีบด่วน ในอันจะรักษาความปลอดภัยสาธารณะ หรือป้องปัดภัยพิบัติสาธารณะ และจะเรียกประชุมรัฐสภาให้ทันท่วงทีมิได้ก็ดี เมื่อกรณีเช่นว่านั้นเกิดขึ้นในระหว่างสภาผู้แทนถูกยุบก็ดี พระมหากษัตริย์จะทรงตราพระราชกำหนดให้ใช้บังคับดั่งเช่นพระราชบัญญัติก็ได้

ในการประชุมรัฐสภาคราวต่อไป ให้เสนอพระราชกำหนดนั้นต่อรัฐสภาโดยไม่ชักช้า ถ้ารัฐสภาคอนุมัติแล้ว พระราชกำหนดนั้นก็ให้มีผลเป็นพระราชบัญญัติต่อไป ถ้ารัฐสภาไม่อนุมัติ พระราชกำหนดนั้นก็เป็นอันตกไป แต่ทั้งนี้ไม่กระทบ กะทั้งกิจการที่ได้เป็นไปในระหว่างที่ใช้พระราชกำหนดนั้น
