เป็นเด็ดขาด

ในการตีความรัฐธรรมนูญตามความในวรรคก่อน ต้อง
มีสมาชิกประชุมไม่ต่ำกว่ากึ่งจำนวนสมาชิกทั้งหมดของทั้ง
สองสภา จึงจะเป็นองค์ประชุม

มาตรา ๑๗๘ บทบัญญัติแห่งกฎหมายใดมีข้อความแย้ง
หรือขัดต่อรัฐธรรมนูญนี้ บทบัญญัตินั้นเป็นอันใช้บังคับ
มิได้

มาตรา ๑๗๙ ในการที่ศาลจะใช้บทบัญญัติแห่งกฎหมาย
บังคับแก่คดีใด ถ้าศาลเห็นว่าบทบัญญัติแห่งกฎหมายนั้น
ต้องด้วยบทบัญญัติมาตรา ๑๗๘ ก็ให้ศาลรอการพิจารณา
พิพากษาคดีไว้ชั่วคราว แล้วส่งความเห็นเช่นว่านั้นตาม
ทางการ เพื่อคณะตุลาการรัฐธรรมนูญจะได้พิจารณาวินิจฉัย
