ฉะยับพิเศษ หน้า ๒๔
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๕๕๒

มาตรา ๔๘ บุคคลมีหน้าที่รักษาไว้ซึ่งระบบการปกครอง ตามรัฐธรรมนูญนี้

มาตรา ๔๙ บุคคลมีหน้าที่เคารพต่อกฎหมาย

มาตรา ๕๐ ในการใช้สิทธิเลือกตั้งและสิทธิออกเสียง ประชามติ บุคคลมีหน้าที่ต้องกระทำโดยสุจริต และมุ่งถึง ประโยชน์ส่วนรวม

มาตรา ๕๑ บุคคลมีหน้าที่เสียภาษีอากรตามที่กฎหมาย บัญญัติ

มาตรา ๕๒ บุคคลมีหน้าที่ช่วยเหลือราชการตามที่กฎหมาย บัญญัติ

มาตรา ๕๓ บุคคลมีหน้าที่รับการศึกษาอบรมชั้นประถม ศึกษา ภายในเงื่อนไขและวิธีการที่กฎหมายบัญญัติ

แนวนโยบายแห่งรัฐ

มาตรา ๕๔ บทบัญญัติในหมวดนี้มีไว้เพื่อเป็นแนวทาง สำหรับการตรากฎหมายและการบริหารราชการตามนโยบาย ดังกำหนดไว้ และไม่ก่อให้เกิดสิทธิในการฟ้องร้องรัฐ
