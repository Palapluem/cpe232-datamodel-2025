ผู้แทนสิ้นสุดลง และวันเลือกตั้งนั้นต้องกำหนดวันเดียว กันทั่วราชอาณาจักร

มาตรา ๕๗ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจ ที่จะยุบสภาผู้แทนเพื่อให้ราษฎรเลือกตั้งสมาชิกใหม่

การยุบสภาผู้แทนให้กระทำโดยพระราชกฤษฎีกา ซึ่ง ต้องกำหนดวันเลือกตั้งสมาชิกใหม่เป็นการเลือกตั้งทั่วไป ภายในเก้าสิบวัน และวันเลือกตั้งนั้นต้องกำหนดวันเดียว กันทั่วราชอาณาจักร

การยุบสภาผู้แทนจะกระทำได้เพียงครั้งเดียวในเหตุการณ์ เดียวกัน
