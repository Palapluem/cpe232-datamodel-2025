ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

เกี่ยวด้วยการเงิน สมาชิกสภาผู้แทนจะเสนอได้คือเมื่อมี
คำรับรองของนายกรัฐมนตรี

ร่างพระราชบัญญัติเกี่ยวด้วยการเงิน หมายความถึงร่าง
พระราชบัญญัติว่าด้วยข้อความต่อไปนี้ทั้งหมด หรือแต่ข้อใด
ข้อหนึ่ง กล่าวคือการตั้งขึ้นหรือยกเลิกหรือลดหรือเปลี่ยน
แปลงแก้ไขหรือผ่อนหรือวางระเบียบการบังคับอันเกี่ยวกับ
ภาษีหรืออากร การจัดสรรหรือรับหรือรักษาหรือจ่ายเงิน
แผ่นดิน หรือการกู้เงิน หรือการค้ำประกัน หรือการใช้
เงินกู้ หรือร่างพระราชบัญญัติว่าด้วยเงินตรา

ในกรณีเป็นที่สงสัย ให้เป็นอำนาจของประธานสภา
ผู้แทนที่จะวินิจฉัยว่าร่างพระราชบัญญัติใดเป็นร่างพระราช
บัญญัติเกี่ยวด้วยการเงินหรือไม่

มาตรา ๑๒๒ ร่างพระราชบัญญัติให้เสนอต่อสภาผู้แทน
ก่อน เมื่อสภาผู้แทนได้พิจารณาลงมติให้ใช้ได้แล้ว ให้นำ
เสนอต่อวุฒิสภาและวุฒิสภาจะต้องพิจารณาให้เสร็จภายใน
กำหนดหกสิบวัน แต่ถ้าร่างพระราชบัญญัตินั้นเป็นร่างพระราช
บัญญัติเกี่ยวด้วยการเงิน วุฒิสภาจะต้องพิจารณาให้เสร็จภาย
