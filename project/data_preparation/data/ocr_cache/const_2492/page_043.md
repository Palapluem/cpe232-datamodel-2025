มาตรา ๑๐๒ ก่อนเข้ารับหน้าที่ สมาชิกวุฒิสภาและ
สมาชิกสภาผู้แทนต้องปฏิญาณตนในที่ประชุมแห่งสภาที่ตน
เป็นสมาชิก ด้วยถ้อยคำดังต่อไปนี้

"ข้าพเจ้า (ชื่อผู้ปฏิญาณ) ขอปฏิญาณว่า จะปฏิบัติ
หน้าที่ตามความเห็นของข้าพเจ้าโดยบริสุทธิ์ใจเพื่อประโยชน์
ส่วนรวมของปวงชนชาวไทย ทั้งจะรักษาไว้และปฏิบัติตาม
ซึ่งรัฐธรรมนูญแห่งราชอาณาจักรไทยทุกประการ"
