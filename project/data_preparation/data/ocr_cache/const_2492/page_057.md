ฉบับพิเศษ หน้า ๕๗
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

เมื่อการเปิดอภิปรายทั่วไปในสภาผู้แทนสิ้นสุดลง โดยมิใช่ด้วยมติให้ผ่านระเบียบวาระเปิดอภิปรายนั้นไป ก็ให้ประธานสภาผู้แทนแจ้งไปยังประธานวุฒิสภา และในกรณีเช่นว่านี้ วุฒิสภาอาจเปิดอภิปรายทั่วไปในปัญหาเดียวกันนั้น และอาจส่งข้อสังเกตไปยังสภาผู้แทนเพื่อประกอบการพิจารณาของสภานั้นได้

การลงมติไว้วางใจหรือไม่ไว้วางใจ ให้สภาผู้แทนกระทำภายหลังที่ได้รับแจ้งผลแห่งการประชุมปรึกษาของวุฒิสภาตามความในวรรคก่อนแล้ว

มาตรา ๑๓๒ ถ้ามีปัญหาเกี่ยวกับราชการแผ่นดิน ที่คณะรัฐมนตรีเห็นสมควรจะฟังความคิดเห็นของสมาชิกวุฒิสภาและสมาชิกสภาผู้แทน นายกรัฐมนตรีจะแจ้งไปยังประธานรัฐสภาขอให้มีการเปิดอภิปรายทั่วไปในที่ประชุมร่วมกันของรัฐสภาก็ได้ ในกรณีเช่นว่านี้รัฐสภาจะลงมติในปัญหาที่อภิปรายมิได้

มาตรา ๑๓๓ การประชุมวุฒิสภาและสภาผู้แทนย่อมเป็นการเปิดเผยตามลักษณะที่กำหนดไว้ในข้อบังคับของ
