มาตรา ๘๓ สมาชิกภาพแห่งสมาชิกวุฒิสภามีกำหนดเวลาคราวละหกปีนับแต่วันที่พระมหากษัตริย์ทรงแต่งตั้งฉะเพาะในวาระเริ่มแรกเมื่อครบกำหนดสามปีให้มีการเปลี่ยนสมาชิกเป็นจำนวนกึ่งหนึ่งโดยวิธีจับสลาก

พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะเลือกและแต่งตั้งผู้ที่ออกตามวาระเป็นสมาชิกอีกได้
