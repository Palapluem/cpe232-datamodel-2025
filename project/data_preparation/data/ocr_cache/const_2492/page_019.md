ฉะบับพิเศษ หน้า ๑๙
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๕๒

บุคคลนั้น จะกระทำได้ก็แต่โดยอาศัยอำนาจตามบทบัญญัติแห่งกฎหมายฉะเพาะเพื่อประโยชน์ในการรักษาความปลอดภัยสาธารณะ หรือเพื่อบังปัดภัยพิบัติสาธารณะ และต้องชดใช้ค่าทดแทนอันเป็นธรรมแก่ผู้ได้รับความเสียหายด้วย

มาตรา ๓๕ บุคคลย่อมมีเสรีภาพบริบูรณ์ในการพูด การเขียน การพิมพ์ และการโฆษณา

การจำกัดเสรีภาพเช่นว่านี้ จะกระทำได้ก็แต่โดยบทบัญญัติแห่งกฎหมายฉะเพาะเพื่อคุ้มครองเสรีภาพของบุคคลอื่น หรือเพื่อหลีกเลี่ยงภาวะคับขัน หรือเพื่อรักษาความสงบเรียบร้อยหรือศีลธรรมอันดีของประชาชน หรือเพื่อบังกันความเสื่อมทรามทางจิตต์ใจของเยาวชน

การปิดโรงพิมพ์หรือห้ามทำการพิมพ์เพื่อบ่นรอนเสรีภาพตามมาตรานี้ จะกระทำมิได้

การให้เสนอเรื่องหรือข้อความในหนังสือพิมพ์ไปให้เจ้าหน้าที่ตรวจก่อนโฆษณา จะกระทำมิได้ เว้นแต่จะกระทำในระหว่างเวลาที่ประเทศอยู่ในภาวะการรบหรือการสงคราม
