ฉบับพิเศษ หน้า ๘
ตอนที่ ๑๗ เล่ม ๖๖ ราชกิจจานุเบกษา ๒๓ มีนาคม ๒๔๙๒

มาตรา ๑๐ พระมหากษัตริย์ทรงใช้อำนาจตุลาการทางศาล

มาตรา ๑๑ พระมหากษัตริย์ทรงดำรงตำแหน่งจอมทัพไทย ทรงเป็นผู้บังคับบัญชาสูงสุดของทหารทั้งปวง

มาตรา ๑๒ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะสถาปนาฐานันดรศักดิ์ และพระราชทานเครื่องราชอิสริยาภรณ์

มาตรา ๑๓ พระมหากษัตริย์ทรงเลือกและแต่งตั้งผู้ทรงคุณวุฒิเป็นประธานองคมนตรีคนหนึ่งและองคมนตรีอีกไม่มากกว่าแปดคนประกอบเป็นคณะองคมนตรี

คณะองคมนตรีมีหน้าที่ถวายความเห็นต่อพระมหากษัตริย์ในพระราชกรณียกิจทั้งปวงที่พระมหากษัตริย์ทรงปรึกษาและมีหน้าที่อื่นตามที่บัญญัติในรัฐธรรมนูญนี้

มาตรา ๑๔ การเลือกและแต่งตั้งองคมนตรีก็ดี การให้ยังคงองคมนตรีพ้นจากตำแหน่งก็ดี ให้เงินไปตามพระราชอัธยาศัย
