ฉบับพิเศษ หน้า ๔ เล่ม ๙๔ ตอนที่ ๑๑๑ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๕๒๐

มาตรา ๗ สภานิติบัญญัติแห่งชาติประกอบด้วยสมาชิกจำนวนไม่น้อยกว่าสามร้อยคนแต่ไม่เกินสี่ร้อยคน ซึ่งพระมหากษัตริย์ทรงแต่งตั้งจากผู้มีสัญชาติไทยโดยกำเนิด ตามที่ประธานสภานโยบายแห่งชาตินำความกราบบังคมทูล

ถ้าตำแหน่งสมาชิกสภานิติบัญญัติแห่งชาติว่างลง พระมหา กษัตริย์จะทรงแต่งตั้งบุคคลผู้มีคุณสมบัติตามวรรคหนึ่งเข้าเป็นสมาชิกแทนก็ได้

ประธานสภานโยบายแห่งชาติเป็นผู้รับสนองพระบรมราชโองการแต่งตั้งสมาชิกสภานิติบัญญัติแห่งชาติ

พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะให้สมาชิกสภานิติบัญญัติแห่งชาติพ้นจากตำแหน่งตามที่ประธานสภานิติบัญญัติแห่งชาติถวายคำแนะนำตามมติของสภานิติบัญญัติแห่งชาติ และประธานสภานิติบัญญัติแห่งชาติเป็นผู้ลงนามรับสนองพระบรมราชโองการให้สมาชิกพ้นจากตำแหน่ง
