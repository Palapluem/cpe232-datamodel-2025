ฉบับพิเศษ หน้า ๙ เล่ม ๙๔ ตอนที่ ๑๑๑ ราชกิจจานุเบกษา ๙ พฤศจิกายน ๒๕๒๐

ให้หัวหน้าคณะปฏิวัติเป็นประธานสถานโยบายแห่งชาติ รองหัวหน้าคณะปฏิวัติ เป็นรองประธานสถานโยบายแห่งชาติ และให้สถานโยบายแห่งชาติแต่งตั้งสมาชิกสถานโยบายแห่งชาติ เป็นเลขาธิการสถานโยบายแห่งชาติคนหนึ่ง และรองเลขาธิการ สถานโยบายแห่งชาติคนหนึ่ง

ในกรณีที่ประธานสถานโยบายแห่งชาติไม่อยู่หรือไม่อาจ ปฏิบัติหน้าที่ได้ ให้รองประธานสถานโยบายแห่งชาติทำหน้าที่ ประธานสถานโยบายแห่งชาติ และในกรณีที่ประธานและรอง ประธานสถานโยบายแห่งชาติไม่อยู่หรือไม่อาจปฏิบัติหน้าที่ได้ ให้สมาชิกสถานโยบายแห่งชาติเลือกสมาชิกคนหนึ่งทำหน้าที่ ประธานสถานโยบายแห่งชาติ

มาตรา ๑๘ สถานโยบายแห่งชาติมีอำนาจหน้าที่กำหนด แนวนโยบายแห่งรัฐ และให้ความคิดเห็นแก่คณะรัฐมนตรีเพื่อ ให้การบริหารราชการแผ่นดินเป็นไปตามแนวนโยบายแห่งรัฐ และมีอำนาจหน้าที่อื่นตามที่บัญญัติไว้ในธรรมนูญการปกครองนี้

มาตรา ๑๙ ในกรณีมีปัญหาเกี่ยวกับนโยบายสำคัญ หรือ เมื่อนายกรัฐมนตรีขอให้พิจารณาปัญหาใด ประธานสถานโยบาย
