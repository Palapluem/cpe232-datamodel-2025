ตอนที่ 75 เล่ม 59 ราชกิจจานุเบกษา 3 ธันวาคม 2485

โดยที่สภาผู้แทนราสดรลงมติว่า สมควรแก้ไขเพิ่มเติม บทบัญญัติว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราสดรใน รัฐธรรมนูญแห่งราชอาณาจักรไทย

จึงมีพระบรมราชโองการให้ตรารัถธัมม์แก้ไขเพิ่มเติม ว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราสดรขึ้นไว้ โดยคำ แนะนำและยินยอมของสภาผู้แทนราสดร ดังต่อไปนี้

มาตรา 1 รัถธัมม์นูญนี้ให้เรียกว่า "รัถธัมม์แก้ไขเพิ่ม เติมว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทนราสดร พุทธศักราช 2485"

มาตรา 2 ให้ใช้รัถธัมม์นูญนี้ตั้งแต่วันประกาศในราชกิจจา นุเบกสาเป็นต้นไป

มาตรา 3 ให้ยกเลิกความในมาตรา 18 ของรัถธัมม์ แห่งราชอาณาจักรไทย และให้ใช้ความต่อไปนี้แทน

"มาตรา 18 สมาชิกสภาผู้แทนราสดรให้หยู่ในตำแหน่ง ได้คราวละสี่ปี แต่ถ้ามีพริติการน์สำคัญกระทบถึงนโยบายพาย ในหรือพายนอก อันทำให้เป็นการพ้นวิสัยหรือมีเหตุขัดข้อง ที่จะให้มีการเลือกตั้งในขณะที่กำหนด เวลาสี่ปีสิ้นสุดลง จะตรา
