ปฏิบัติหน้าที่ประธานรัฐสภาได้ ให้ประธานวุฒิสภาทำหน้าที่ประธานรัฐสภาแทน

ประธานรัฐสภามีอำนาจหน้าที่ตามที่บัญญัติไว้ในรัฐธรรมนูญนี้ และดำเนินกิจการของรัฐสภา
ในกรณีประชุมร่วมกันให้เป็นไปตามข้อบังคับ

ประธานรัฐสภาและผู้ทำหน้าที่แทนประธานรัฐสภาต้องวางตนเป็นกลางในการปฏิบัติหน้าที่

กฎหมายได้ก็แต่โดยคำแนะนำและยินยอมของรัฐสภา

ของรัฐสภาแล้ว ให้นายกรัฐมนตรีนำขึ้นทูลเกล้าทูลกระหม่อมถวายภายในยี่สิบวันนับแต่วันที่ได้รับร่าง

พระปรมาภิไธย และเมื่อประกาศในราชกิจจานุเบกษาแล้ว ให้ใช้บังคับเป็นกฎหมายได้

ไม่ทรงเห็นชอบด้วยและพระราชทานคืนมายังรัฐสภา หรือเมื่อพ้นเก้าสิบวันแล้วมิได้พระราชทานคืนมา
