๑๑ ตุลาคม ๒๕๔๐

วันประกาศใช้รัฐธรรมนูญนี้ จนกว่าจะครบวาระการดำรงตำแหน่งของสมาชิกซึ่งมาจากการเลือกตั้งของ สภาองค์การบริหารส่วนตำบลดังกล่าว
(๘) มิให้นำบทบัญญัติมาตรา ๒๘๘ วรรคสอง มาใช้บังคับกับองค์ประกอบคณะกรรมการ พนักงานส่วนท้องถิ่น จนกว่าจะมีการแก้ไขเพิ่มเติมหรือตรากฎหมายขึ้นใหม่เพื่ออนุวัตการให้เป็นไปตาม บทบัญญัติดังกล่าว ซึ่งต้องไม่เกินสองปีนับแต่วันประกาศใช้รัฐธรรมนูญนี้
มาตรา ๓๓๖ เมื่อครบห้าปีนับแต่วันประกาศใช้รัฐธรรมนูญนี้ คณะกรรมการการเลือกตั้ง คณะตุลาการศาลรัฐธรรมนูญ หรือคณะกรรมการป้องกันและปราบปรามการทุจริตแห่งชาติ มีอำนาจทำ รายงานเสนอความเห็นต่อรัฐสภาและคณะรัฐมนตรีเกี่ยวกับการแก้ไขเพิ่มเติมรัฐธรรมนูญนี้หรือกฎหมาย อื่นได้
