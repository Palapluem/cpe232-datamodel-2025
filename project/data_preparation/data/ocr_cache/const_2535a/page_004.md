เล่ม ๑๐๙ ตอนที่ ๗๒ ราชกิจจานุเบกษา ๓๐ มิถุนายน ๒๕๓๕

หมายเหตุ :- เหตุผลในการประกาศใช้รัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไข เพิ่มเติมฉบับนี้ คือ โดยที่เป็นการสมควรแก้ไขเพิ่มเติมรัฐธรรมนูญแห่งราชอาณา จักรไทยเกี่ยวกับผู้ดำรงตำแหน่งประธานรัฐสภา ข้อบังคับการประชุมของรัฐสภาและ องค์ประกอบของคณะตุลาการรัฐธรรมนูญให้เหมาะสมยิ่งขึ้น จึงจำเป็นต้องตรา รัฐธรรมนูญนี้
