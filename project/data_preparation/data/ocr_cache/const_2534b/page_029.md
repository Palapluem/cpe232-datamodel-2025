ฉบับพิเศษ หน้า ๒๙ เล่ม ๑๐๘ ตอนที่ ๒๑๖ ราชกิจจานุเบกษา ๙ ธันวาคม ๒๕๓๔

มาตรา ๙๖ สมาชิกวุฒิสภาต้องไม่รับสัมปทานจากรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจ หรือเป็นคู่สัญญากับรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐ หรือรัฐวิสาหกิจอันมีลักษณะเป็นการผูกขาดตัดตอน ทั้งนี้ ไม่ว่าโดยทางตรงหรือทางอ้อม เว้นแต่กรณีที่ได้รับสัมปทานหรือเป็นคู่สัญญาอยู่ก่อนได้รับแต่งตั้งเป็นสมาชิกวุฒิสภา

(๖) เป็นสมาชิกสภาท้องถิ่นหรือผู้บริหารท้องถิ่นซึ่งได้รับเลือกตั้ง
