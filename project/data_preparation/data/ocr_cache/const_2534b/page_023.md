ฉบับพิเศษ หน้า ๒๓ เล่ม ๑๐๘ ตอนที่ ๒๑๖ ราชกิจจานุเบกษา ๙ ธันวาคม ๒๕๓๔

มาตรา ๗๗ รัฐพึงสนับสนุนให้เอกชนมีบทบาทในทางเศรษฐกิจ
รัฐไม่พึงประกอบกิจการอันมีลักษณะเป็นธุรกิจหรือเป็นการแข่งขัน กับเอกชน เว้นแต่มีความจำเป็นเพื่อประโยชน์ในการรักษาความมั่นคง ของรัฐ การรักษาประโยชน์ส่วนรวม หรือการจัดให้มีการสาธารณูปโภค
รัฐพึงวางมาตรการมิให้มีการผูกขาดตัดตอนในทางเศรษฐกิจโดย เอกชนที่มิได้อาศัยอำนาจตามบทบัญญัติแห่งกฎหมาย ทั้งนี้ ไม่ว่า การผูกขาดตัดตอนนั้นจะเป็นโดยทางตรงหรือทางอ้อม

มาตรา ๗๘ รัฐพึงวางนโยบายประชากรให้เหมาะสมกับทรัพยากร ของชาติ ภาวะทางเศรษฐกิจและสังคม และความเจริญในทางวิทยาการ

มาตรา ๗๙ รัฐพึงสงเคราะห์ผู้ประสบภัยเนื่องในการปฏิบัติหน้าที่ เพื่อประเทศชาติ หรือในการช่วยเหลือราชการ หรือปฏิบัติตามหน้าที่ มนุษยธรรม หรือเนื่องจากสาธารณภัย

มาตรา ๘๐ รัฐพึงจัดให้มีการสังคมสงเคราะห์ ส่งเสริมและสนับ สนุนให้เอกชนมีส่วนร่วมในการสังคมสงเคราะห์

มาตรา ๘๑ รัฐพึงช่วยเหลือและสงเคราะห์ผู้สูงอายุและผู้พิการ ให้มีสุขภาพ กำลังใจ และความหวังในชีวิตเพื่อสามารถดำรงตนอยู่ได้ ตามสมควร

มาตรา ๘๒ รัฐพึงส่งเสริมให้ประชากรวัยทำงานมีงานทำ และ พึ่งคุ้มครองแรงงาน โดยเฉพาะแรงงานเด็กและแรงงานหญิงกับจัด ระบบแรงงานสัมพันธ์ รวมทั้งค่าตอบแทนแรงงานให้เป็นธรรม

มาตรา ๘๓ รัฐพึงส่งเสริมการสาธารณสุขที่ได้มาตรฐานโดยทั่วถึง
