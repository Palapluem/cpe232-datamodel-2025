ฉบับพิเศษ หน้า ๒๕
เล่ม ๑๐๘ ตอนที่ ๒๑๖ ราชกิจจานุเบกษา ๙ ธันวาคม ๒๕๓๔

ดำเนินกิจการของรัฐสภาในกรณีประชุมร่วมกันให้เป็นไปตามข้อบังคับ
รองประธานรัฐสภามีอำนาจหน้าที่ตามที่บัญญัติในรัฐธรรมนูญนี้
และตามที่ประธานรัฐสภามอบหมาย

มาตรา ๘๗ ร่างพระราชบัญญัติจะตราขึ้นเป็นกฎหมายได้ก็แต่
โดยคำแนะนำและยินยอมของรัฐสภา

มาตรา ๘๘ ร่างพระราชบัญญัติที่ได้รับความเห็นชอบของรัฐสภา
แล้ว ให้นายกรัฐมนตรีนำขึ้นทูลเกล้า ฯ ถวายภายในสามสิบวันนับแต่
วันที่ได้รับร่างพระราชบัญญัตินั้นจากรัฐสภาเพื่อพระมหากษัตริย์ทรง
ลงพระปรมาภิไธย และเมื่อได้ประกาศในราชกิจจานุเบกษาแล้ว ให้ใช้
บังคับเป็นกฎหมายได้

มาตรา ๘๙ ร่างพระราชบัญญัติใดพระมหากษัตริย์ไม่ทรงเห็น
ชอบด้วยและพระราชทานคืนมายังรัฐสภา หรือเมื่อพ้นเก้าสิบวันแล้ว
มิได้พระราชทานคืนมา รัฐสภาจะต้องปรึกษาร่างพระราชบัญญัตินั้นใหม่
ถ้ารัฐสภาลงมติยืนยันตามเดิมด้วยคะแนนเสียงไม่น้อยกว่าสองในสาม
ของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของทั้งสองสภาแล้ว ให้นายกรัฐ
มนตรีนำร่างพระราชบัญญัตินั้นขึ้นทูลเกล้า ฯ ถวายอีกครั้งหนึ่ง เมื่อ
พระมหากษัตริย์มิได้ทรงลงพระปรมาภิไธยพระราชทานคืนมาภายใน
สามสิบวัน ให้นายกรัฐมนตรีนำพระราชบัญญัตินั้นประกาศในราชกิจจา
นุเบกษาใช้บังคับเป็นกฎหมายได้เสมือนหนึ่งว่าพระมหากษัตริย์ได้ทรง
ลงพระปรมาภิไธยแล้ว
