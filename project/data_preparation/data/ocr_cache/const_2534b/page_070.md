ฉบับพิเศษ หน้า ๗๐ เล่ม ๑๐๘ ตอนที่ ๒๑๖ ราชกิจจานุเบกษา ๙ ธันวาคม ๒๕๓๔

มาตรา ๑๙๔ ศาลทหารมีอำนาจพิจารณาพิพากษาคดีตามที่กฎหมายบัญญัติ
การแต่งตั้งและการให้ตุลาการศาลทหารพ้นจากตำแหน่ง ให้เป็นไปตามที่กฎหมายบัญญัติ

มาตรา ๑๙๕ ในกรณีที่มีปัญหาเกี่ยวกับอำนาจหน้าที่ระหว่างศาลยุติธรรมกับศาลอื่น หรือระหว่างศาลอื่นด้วยกัน ให้คณะตุลาการรัฐธรรมนูญเป็นผู้วินิจฉัย

หมวด ๙
การปกครองท้องถิ่น

มาตรา ๑๙๖ การจัดการปกครองท้องถิ่นต้องเป็นไปตามหลักแห่งการปกครองตนเองตามเจตนารมณ์ของประชาชนในท้องถิ่น ทั้งนี้ ตามบทบัญญัติแห่งกฎหมาย
การควบคุมหรือกำกับดูแลการปกครองท้องถิ่นต้องทำเท่าที่จำเป็น เพื่อการคุ้มครองประโยชน์ของประชาชนในท้องถิ่นหรือประโยชน์ของประเทศเป็นส่วนรวม

มาตรา ๑๙๗ การจัดระเบียบการปกครองท้องถิ่น ให้มีสภาท้องถิ่น และคณะผู้บริหารท้องถิ่นหรือผู้บริหารท้องถิ่น หรือมีรูปแบบอื่นตามที่กฎหมายบัญญัติ

มาตรา ๑๙๘ สมาชิกสภาท้องถิ่นให้มาจากการเลือกตั้งเป็นหลัก
