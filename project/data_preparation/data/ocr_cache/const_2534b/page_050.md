ฉบับพิเศษ หน้า ๕๐ เล่ม ๑๐๘ ตอนที่ ๒๑๖ ราชกิจจานุเบกษา ๙ ธันวาคม ๒๕๓๔

พระราชบัญญัติที่เสนอไปนั้นเป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงิน คำแจ้งของประธานสภาผู้แทนราษฎรให้ถือเป็นเด็ดขาด

ในกรณีที่ประธานสภาผู้แทนราษฎรมิได้แจ้งไปว่าร่างพระราชบัญญัติใดเป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงิน ให้ถือว่าร่างพระราชบัญญัตินั้นไม่เป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงิน

มาตรา ๑๔๑ ภายใต้บังคับมาตรา ๑๔๖ เมื่อวุฒิสภาได้พิจารณาร่างพระราชบัญญัติเสร็จแล้ว

(๑) ถ้าเห็นชอบด้วยกับสภาผู้แทนราษฎร ให้ดำเนินการต่อไปตามมาตรา ๘๘

(๒) ถ้าไม่เห็นชอบด้วยกับสภาผู้แทนราษฎร ให้ยับยั้งร่างพระราชบัญญัตินั้นไว้ก่อน และส่งร่างพระราชบัญญัตินั้นคืนไปยังสภาผู้แทนราษฎร

(๓) ถ้าแก้ไขเพิ่มเติม ให้ส่งร่างพระราชบัญญัติตามที่แก้ไขเพิ่มเติมนั้นไปยังสภาผู้แทนราษฎร ถ้าสภาผู้แทนราษฎรเห็นว่าเป็นการแก้ไขเพิ่มเติมเล็กน้อยและเห็นชอบด้วยกับการแก้ไขเพิ่มเติม ให้ดำเนินการต่อไปตามมาตรา ๘๘ ถ้าเป็นกรณีอื่นให้แต่ละสภาตั้งบุคคลที่เป็นหรือมิได้เป็นสมาชิกแห่งสภานั้น ๆ มีจำนวนเท่ากันตามที่สภาผู้แทนราษฎรกำหนด ประกอบเป็นคณะกรรมาธิการร่วมกัน เพื่อพิจารณาร่างพระราชบัญญัตินั้น และให้คณะกรรมาธิการร่วมกันรายงานและเสนอร่างพระราชบัญญัติที่คณะกรรมาธิการร่วมกันได้พิจารณาแล้วต่อสภาทั้งสอง ถ้าสภาทั้งสองต่างเห็นชอบด้วยร่างพระราช
