มาตรา ๑๖๘ ถ้าตำแหน่งตุลาการรัฐธรรมนูญซึ่งรัฐสภาแต่งตั้งว่างลงเพราะเหตุอื่นใด นอกจากถึงกราวออกตามมาตรา ๑๖๗ (๑) ให้รัฐสภาแต่งตั้งตุลาการรัฐธรรมนูญเข้ามาแทนภายในสามสิบวัน
