ฉบับพิเศษ หน้า ๒๙ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

มาตรา ๗๙ สมาชิกภาพของสมาชิกวุฒิสภามีวาระคราวละ หกปีนับแต่วันที่พระมหากษัตริย์ทรงแต่งตั้ง

ในวาระเริ่มแรกเมื่อครบกำหนดสามปีนับแต่วันที่พระมหา กษัตริย์ทรงแต่งตั้งสมาชิกเป็นกรั้งแรก ให้มีการจับสลากเพื่อให้ สมาชิกพ้นจากตำแหน่งเป็นจำนวนกึ่งหนึ่งของจำนวนสมาชิก ทั้งหมด และให้ถือว่าการสิ้นสุดแห่งสมาชิกภาพโดยการจับสลาก เป็นการออกตามวาระด้วย

พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะแต่งตั้งผู้ที่ ออกตามวาระ เป็นสมาชิกอีกได้
