ฉบับพิเศษ หน้า ๒๓ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

หมวด ๕
แนวนโยบายแห่งรัฐ

มาตรา ๕๓ บทบัญญัติในหมวดนี้มีไว้เพื่อเป็นแนวทางสำหรับการตรากฎหมาย และการบริหารราชการตามนโยบายดังกำหนดไว้ และไม่ก่อให้เกิดสิทธิในการฟ้องร้องรัฐ

มาตรา ๕๔ รัฐจะต้องรักษาไว้ซึ่งเอกราช

มาตรา ๕๕ รัฐพึงส่งเสริมสัมพันธไมตรีระหว่างประเทศ และถือหลักถ้อยที่ถ้อยปฏิบัติต่อกัน

มาตรา ๕๖ รัฐพึงร่วมมือกับนานาประเทศในการรักษาความยุติธรรมระหว่างประเทศ และผดุงสันติสุขของโลก

มาตรา ๕๗ กำลังทหารพึงมีโดยเหมาะสมแก่ความจำเป็นสำหรับรักษาเอกราช ความมั่นคงและผลประโยชน์แห่งชาติ

มาตรา ๕๘ กำลังทหารเป็นของชาติ พึงใช้เพื่อการรบหรือการสงคราม หรือเพื่อปราบปรามการจลาจล

การใช้กำลังทหารเพื่อการอื่น ให้เป็นไปตามบทบัญญัติแห่งกฎหมาย
