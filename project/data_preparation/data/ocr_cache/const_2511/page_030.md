ฉบับพิเศษ หน้า ๓๐ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

(๖) ถูกจำคุกโดยคำพิพากษาโทษจำคุก เว้นแต่ในความผิดอันได้กระทำโดยประมาท หรือความผิดที่เป็นลหุโทษ หรือความผิดที่มีกำหนดโทษชั้นลหุโทษ

มาตรา ๘๑ ถ้าตำแหน่งสมาชิกวุฒิสภาว่างลงเพราะเหตุอื่นใด นอกจากถึงคราวออกตามวาระ พระมหากษัตริย์จะได้ทรงแต่งตั้งบุคคลผู้มีลักษณะต้องตามที่บัญญัติไว้ในมาตรา ๗๘ เข้ามาเป็นสมาชิกแทน สมาชิกซึ่งเข้ามาแทนนั้นย่อมอยู่ในตำแหน่งได้เพียงครบตามวาระของผู้ซึ่งตนแทน

## ส่วนที่ ๓ สภาผู้แทน

มาตรา ๘๒ สภาผู้แทนประกอบด้วยสมาชิกซึ่งราษฎรเลือกตั้ง มีจำนวนตามเกณฑ์ที่บัญญัติไว้ในมาตรา ๘๓

การเลือกตั้งสมาชิกสภาผู้แทนให้ใช้วิธีออกเสียงลงคะแนนโดยตรงและลับ และให้ถือเขตจังหวัดเป็นเกณฑ์

การเลือกตั้งจะใช้วิธีรวมเขตหรือแบ่งเขต ให้เป็นไปตามกฎหมายว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทน
