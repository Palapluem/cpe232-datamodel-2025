ฉบับพิเศษ หน้า ๑๖ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

ก่อนที่จะมีคำพิพากษาอันถึงที่สุดแสดงว่าบุคคลใดได้กระทำความผิด จะปฏิบัติต่อบุคคลนั้นเสมือนเป็นผู้กระทำความผิดมิได้

คำขอประกันผู้ต้องหาหรือจำเลยในคดีอาญา จะต้องได้รับการพิจารณา และจะเรียกหลักประกันจนเกินควรแก่กรณีมิได้ การไม่ให้ประกันต้องอาศัยเหตุตามหลักเกณฑ์ที่บัญญัติไว้ โดยเฉพาะในกฎหมาย และจะต้องแจ้งเหตุที่ไม่ให้ประกันแก่ผู้ต้องหาหรือจำเลยทราบ

บุคคลผู้ถูกคุมขังหรือถูกจำคุก ย่อมมีสิทธิที่จะได้รับการเยี่ยมตามสมควร

มาตรา ๒๙ บุคคลย่อมมีเสรีภาพบริบูรณ์ในร่างกาย

การจับกุมคุมขังหรือตรวจค้นตัวบุคคลไม่ว่าในกรณีใด ๆ จะกระทำได้ก็แต่โดยอาศัยอำนาจตามบทบัญญัติแห่งกฎหมาย แต่ผู้ถูกจับกุมหรือถูกตรวจค้นจะต้องได้รับแจ้งเหตุพร้อมด้วยรายละเอียดตามสมควรในการที่ถูกจับหรือถูกตรวจค้นโดยไม่ชักช้า และผู้ถูกคุมขังย่อมมีสิทธิที่จะพบและปรึกษาทนายความ เป็นการเฉพาะตัวได้

ในกรณีที่มีการคุมขังตัวบุคคล ผู้ถูกคุมขังเองก็ดี พนักงานอัยการก็ดี บุคคลอื่นใดเพื่อประโยชน์ของผู้ถูกคุมขังก็ดี มีสิทธิ
