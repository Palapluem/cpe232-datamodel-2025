ฉบับพิเศษ หน้า ๓๔ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

มาตรา ๙๐ ภายใต้บังคับบทบัญญัติแห่งรัฐธรรมนูญนี้ หลักเกณฑ์และวิธีการเลือกตั้งให้เป็นไปตามกฎหมายว่าด้วยการเลือกตั้งสมาชิกสภาผู้แทน

มาตรา ๙๑ อายุของสภาผู้แทนมีกำหนดคราวละสี่ปีนับแต่วันเปิดประชุมรัฐสภาครั้งแรก

มาตรา ๙๒ การเลือกตั้งสมาชิกสภาผู้แทน จะกระทำได้เมื่อได้มีพระราชกฤษฎีกาให้เลือกตั้งสมาชิกสภาผู้แทนแล้ว พระราชกฤษฎีกานั้นให้ระบุระยะเวลารับสมัครผู้สมัครรับเลือกตั้งและวันเลือกตั้งด้วย ในกรณีการเลือกตั้งทั่วไป ให้กำหนดวันเลือกตั้งวันเดียวกันทั่วราชอาณาจักร

มาตรา ๙๓ พระมหากษัตริย์ทรงไว้ซึ่งพระราชอำนาจที่จะยุบสภาผู้แทนเพื่อให้ราษฎรเลือกตั้งสมาชิกใหม่

การยุบสภาผู้แทนให้กระทำโดยพระราชกฤษฎีกา ซึ่งต้องกำหนดวันเลือกตั้งสมาชิกสภาผู้แทนใหม่เป็นการเลือกตั้งทั่วไปภายในเก้าสิบวัน

มาตรา ๙๔ สมาชิกภาพของสมาชิกสภาผู้แทนเริ่มแต่วันเปิดประชุมรัฐสภาครั้งแรก
