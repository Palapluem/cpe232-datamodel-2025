ฉบับพิเศษ หน้า ๓๖
เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

ส่วนที่ ๔
บทที่ใช้แก่สภาทั้งสอง

มาตรา ๙๗ สภาชิกวุฒิสภาและสมาชิกสภาผู้แทนย่อมเป็นผู้แทนปวงชนชาวไทย ไม่อยู่ในความผูกมัดแห่งอาณัติมอบหมายใด ๆ และต้องปฏิบัติหน้าที่ตามความเห็นของตนโดยบริสุทธิ์ใจ เพื่อประโยชน์ส่วนรวมของปวงชนชาวไทย

มาตรา ๙๘ ก่อนเข้ารับหน้าที่ สภาชิกวุฒิสภาและสมาชิกสภาผู้แทน ต้องปฏิญาณตนในที่ประชุมแห่งสภาที่ตนเป็นสมาชิกด้วยถ้อยคำดังต่อไปนี้
"ข้าพเจ้า (ชื่อผู้ปฏิญาณ) ขอปฏิญาณว่า ข้าพเจ้าจะปฏิบัติหน้าที่ตามความเห็นของข้าพเจ้าโดยบริสุทธิ์ใจ เพื่อประโยชน์ส่วนรวมของปวงชนชาวไทย ทั้งจะรักษาไว้และปฏิบัติตามซึ่งรัฐธรรมนูญแห่งราชอาณาจักรไทยทุกประการ"

มาตรา ๙๙ วุฒิสภาและสภาผู้แทนแต่ละสภา มีประธานสภาคนหนึ่งและรองประธานสภาคนหนึ่งหรือสองคน ซึ่งพระมหากษัตริย์ทรงแต่งตั้งจากสมาชิกแห่งสภานั้นๆ ตามมติของสภา

มาตรา ๑๐๐ ประธานและรองประธานวุฒิสภาดำรงตำแหน่งจนถึงวันก่อนวันเลือกประธานและรองประธานวุฒิสภาใหม่ ซึ่งจะต้องกระทำเมื่อถึงคราวที่มีการเปลี่ยนสมาชิกกึ่งหนึ่ง
