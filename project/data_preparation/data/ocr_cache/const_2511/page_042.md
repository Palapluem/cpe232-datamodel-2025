ฉบับพิเศษ หน้า ๔๒ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

คำสั่งปล่อยตามวรรคหนึ่งให้มีผลบังคับตั้งแต่วันสั่งปล่อย จนถึงวันสุดท้ายแห่งสมัยประชุม

มาตรา ๑๑๗ ร่างพระราชบัญญัติจะเสนอได้ก็แต่โดยคณะรัฐมนตรี สมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน แต่ร่างพระราชบัญญัติเกี่ยวด้วยการเงิน สมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน จะเสนอได้ก็ต่อเมื่อมีคำรับรองของนายกรัฐมนตรี

ร่างพระราชบัญญัติเกี่ยวด้วยการเงิน หมายความถึงร่างพระราชบัญญัติว่าด้วยข้อความต่อไปนี้ทั้งหมด หรือแต่ข้อใด ข้อหนึ่ง กล่าวคือ การตั้งขึ้นหรือยกเลิกหรือลดหรือเปลี่ยนแปลงแก้ไขหรือผ่อนหรือวางระเบียบการบังคับอันเกี่ยวกับภาษีหรืออากร การจัดสรรหรือรับหรือรักษาหรือจ่ายเงินแผ่นดิน หรือการกู้เงิน หรือการค้ำประกันหรือการใช้เงินกู้ หรือร่างพระราชบัญญัติว่าด้วยเงินตรา

ในกรณีเป็นที่สงสัยว่าร่างพระราชบัญญัติใดเป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงินหรือไม่ ให้เป็นอำนาจของประธานแห่งสภาที่ได้รับร่างพระราชบัญญัตินั้นจากคณะรัฐมนตรี สมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทน แล้วแต่กรณี เป็นผู้วินิจฉัย
