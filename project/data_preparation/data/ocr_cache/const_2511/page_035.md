(๑) ถึงคราวออกตามอายุของสภาผู้แทน หรือมีการยุบ สภาผู้แทน

(๓) ลาออก
(๔) ขาดคุณสมบัติตามมาตรา ๘๕ หรือมาตรา ๘๘
(๕) มีลักษณะต้องห้ามตามที่บัญญัติไว้ในมาตรา ๘๖ (๑)
(๒) (๓) หรือ (๕) หรือมาตรา ๘๙ (๑) (๒) (๓) (๕) หรือ (๖)
(๖) ถูกจำคุกโดยคำพิพากษาโทษจำคุก เว้นแต่ในความ ผิดอันได้กระทำโดยประมาท หรือความผิดที่เป็นลหุโทษ หรือ ความผิดที่มีกำหนดโทษชั้นลหุโทษ

มาตรา ๙๖ ถ้าตำแหน่งสมาชิกว่างลงเพราะเหตุอื่นใดนอก จากถึงคราวออกตามอายุของสภาผู้แทน หรือเมื่อมีการยุบสภา ผู้แทน ให้มีการเลือกตั้งสมาชิกขึ้นแทนภายในเก้าสิบวัน เว้นแต่ อายุของสภาผู้แทนจะเหลือไม่ถึงหนึ่งร้อยแปดสิบวัน

สมาชิกภาพของสมาชิกผู้เข้ามาแทนนั้นเริ่มแต่วันเข้ารับ หน้าที่ และอยู่ในตำแหน่งได้เพียงเท่าอายุของสภาที่เหลืออยู่
