ฉบับพิเศษ หน้า ๔๔ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

หนึ่ง ให้ประธานแห่งสภาที่เสนอร่างพระราชบัญญัติไปยังอีกสภาหนึ่งนั้น แจ้งไปตามความเห็นของประธานแห่งสภานั้นด้วย ว่า ร่างพระราชบัญญัติที่เสนอไปนั้นเป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงินหรือไม่ คำแจ้งของประธานแห่งสภาให้ถือเป็นเด็ดขาด

ในกรณีที่ประธานแห่งสภามิได้แจ้งไป ว่าร่างพระราชบัญญัติใดเป็นร่างพระราชบัญญัติเกี่ยวด้วยการเงินหรือไม่ ให้ถือว่าร่างพระราชบัญญัตินั้นมิใช่ร่างพระราชบัญญัติเกี่ยวด้วยการเงิน

มาตรา ๑๒๐ เมื่อวุฒิสภาหรือสภาผู้แทนได้พิจารณาร่างพระราชบัญญัติเสร็จแล้ว

(๑) ถ้าเห็นชอบด้วยกับสภาผู้แทนหรือวุฒิสภาที่เสนอร่างพระราชบัญญัตินั้นมา ก็ให้ดำเนินการต่อไปตามมาตรา ๗๔

(๒) ถ้าไม่เห็นชอบด้วยกับสภาผู้แทนหรือวุฒิสภาที่เสนอร่างพระราชบัญญัตินั้นมา ในกรณีที่ร่างพระราชบัญญัตินั้นเป็นร่างพระราชบัญญัติที่สภาผู้แทนเสนอมา ก็ให้ยับยั้งร่างพระราชบัญญัตินั้นไว้ก่อน และส่งร่างพระราชบัญญัตินั้นคืนไปยังสภาผู้แทน ในกรณีที่ร่างพระราชบัญญัตินั้นเป็นร่างพระราชบัญญัติที่วุฒิสภาเสนอมา ก็ให้ร่างพระราชบัญญัตินั้นตกไป

(๓) ถ้าแก้ไขเพิ่มเติม ก็ให้ส่งร่างพระราชบัญญัติตามที่แก้ไขเพิ่มเติมนั้นไปยังสภาผู้แทนหรือวุฒิสภาที่เสนอร่างพระ
