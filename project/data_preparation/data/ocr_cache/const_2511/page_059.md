ฉบับพิเศษ หน้า ๕๙ เล่ม ๘๕ ตอนพิเศษ ราชกิจจานุเบกษา ๒๐ มิถุนายน ๒๕๑๑

ธรรมดาที่มีอยู่ตามกฎหมายสำหรับพิจารณาพิพากษาคดีนั้น จะกระทำมิได้

มาตรา ๑๖๐ การบัญญัติกฎหมายให้มีผลเป็นการเปลี่ยนแปลงหรือแก้ไขเพิ่มเติมกฎหมายว่าด้วยธรรมนูญศาลหรือวิธีพิจารณา เพื่อใช้แก่คดีใดคดีหนึ่งโดยเฉพาะ จะกระทำมิได้

มาตรา ๑๖๑ ผู้พิพากษามีอิสระในการพิจารณาพิพากษา อรรถคดีให้เป็นไปตามกฎหมาย

มาตรา ๑๖๒ พระมหากษัตริย์ทรงแต่งตั้ง ย้ายและถอดถอน ผู้พิพากษา

มาตรา ๑๖๓ การแต่งตั้ง การย้ายและการถอดถอนผู้พิพากษา จะต้องได้รับความเห็นชอบของคณะกรรมการตุลาการตามกฎหมายว่าด้วยระเบียบข้าราชการฝ่ายตุลาการก่อน แล้วจึงนำความกราบบังคมทูล

การเลื่อนตำแหน่งและการเลื่อนเงินเดือนผู้พิพากษา จะต้องได้รับความเห็นชอบของคณะกรรมการตุลาการตามกฎหมายว่าด้วยระเบียบข้าราชการฝ่ายตุลาการ
