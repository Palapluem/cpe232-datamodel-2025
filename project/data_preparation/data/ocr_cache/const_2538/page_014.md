หน้า ๑๔
เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

การจัดระบบการศึกษาอบรมเป็นหน้าที่ของรัฐโดยเฉพาะ สถานศึกษา ทั้งปวงย่อมอยู่ภายใต้การกำกับดูแลของรัฐ

การศึกษาอบรมภาคบังคับในสถานศึกษาของรัฐ จะต้องจัดให้โดย ไม่เก็บค่าเล่าเรียนและโดยทั่วถึงอย่างมีประสิทธิภาพ

การศึกษาอบรมขั้นอุดมศึกษา รัฐพึงจัดให้สถานศึกษาดำเนินกิจการ ได้โดยอิสระภายในขอบเขตตามที่กฎหมายบัญญัติ

รัฐพึงช่วยเหลือผู้ยากไร้และด้อยโอกาสให้ได้รับทุนและปัจจัยต่าง ๆ ในการศึกษาอบรมและการฝึกอาชีพ

มาตรา ๖๖ รัฐพึงสนับสนุนการค้นคว้าวิจัยในศิลปะและวิทยาการ ต่าง ๆ และพึงส่งเสริมและเร่งรัดให้มีการพัฒนาวิทยาศาสตร์และเทคโนโลยี เพื่อนำมาใช้ในการพัฒนาประเทศ

มาตรา ๖๗ รัฐพึงรักษา ส่งเสริมและพัฒนาความเสมอภาคของชาย และหญิง

มาตรา ๖๘ รัฐพึงสนับสนุนและส่งเสริมการพัฒนาพลเมืองของชาติ โดยเฉพาะอย่างยิ่งเด็กและเยาวชนให้เป็นผู้มีความสมบูรณ์ทั้งทางร่างกาย จิตใจ สติปัญญา คุณธรรม และจริยธรรม

มาตรา ๖๙ รัฐพึงส่งเสริมประชาชนให้เข้าใจและเลื่อมใสศรัทธาใน การปกครองระบอบประชาธิปไตยอันมีพระมหากษัตริย์ทรงเป็นประมุข

รัฐพึงส่งเสริมให้ประชาชนเข้าใจในการปกครองส่วนท้องถิ่น ตลอดทั้ง สนับสนุนท้องถิ่นให้มีสิทธิปกครองตนเอง ทั้งนี้ ตามที่กฎหมายบัญญัติ

มาตรา ๗๐ รัฐพึงจัดให้มีแผนพัฒนาการเมืองที่สอดคล้องกับแนว
