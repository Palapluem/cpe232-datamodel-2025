หน้า ๓๕
เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

ประธานและรองประธานสภาผู้แทนราษฎรดำรงตำแหน่งจนสิ้นอายุ ของสภาหรือมีการยุบสภา

ประธานและรองประธานวุฒิสภา และประธานและรองประธานสภา ผู้แทนราษฎรอย่อมพ้นจากตำแหน่งก่อนถึงวาระตามวรรคหนึ่งหรือวรรคสอง แล้วแต่กรณี เมื่อ

(๑) ขาดจากสมาชิกภาพแห่งสภาที่ตนเป็นสมาชิก
(๒) ลาออกจากตำแหน่ง
(๓) ดำรงตำแหน่งรัฐมนตรีหรือข้าราชการการเมืองอื่น
(๔) ต้องคำพิพากษาให้จำคุก

มาตรา ๑๒๗ ประธานวุฒิสภาและประธานสภาผู้แทนราษฎร มีอำนาจ หน้าที่ดำเนินกิจการของสภานั้นๆ ให้เป็นไปตามข้อบังคับ รองประธาน มีอำนาจหน้าที่ตามที่ประธานมอบหมาย และปฏิบัติหน้าที่แทนประธาน เมื่อประธานไม่อยู่หรือไม่สามารถปฏิบัติหน้าที่ได้

มาตรา ๑๒๘ เมื่อประธานและรองประธานวุฒิสภาหรือประธานและ รองประธานสภาผู้แทนราษฎรไม่อยู่ในที่ประชุม ให้สมาชิกแห่งสภานั้น ๆ เลือกตั้งกันขึ้นเองเป็นประธานในคราวประชุมนั้น

มาตรา ๑๒๙ การประชุมวุฒิสภาก็ดี การประชุมสภาผู้แทนราษฎรก็ดี ต้องมีสมาชิกมาประชุมไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่ มีอยู่ของแต่ละสภา จึงจะเป็นองค์ประชุม เว้นแต่ในกรณีการพิจารณาระเบียบ วาระกระทู้ถามตามมาตรา ๑๕๕ สภาผู้แทนราษฎรจะกำหนดเรื่ององค์ประชุม ไว้ในข้อบังคับเป็นอย่างอื่นก็ได้
