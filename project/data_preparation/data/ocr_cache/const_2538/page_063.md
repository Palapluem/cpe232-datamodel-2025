**ประธานรัฐสภาเป็นประธานตุลาการรัฐธรรมนูญ**

ในระหว่างที่อายุของสภาผู้แทนราษฎรสิ้นสุดลง หรือสภาผู้แทนราษฎรถูกยุบให้ตุลาการรัฐธรรมนูญโดยตำแหน่งตามวรรคหนึ่ง ประกอบด้วย ประธานวุฒิสภา ประธานศาลฎีกา และอัยการสูงสุด ในกรณีเช่นนั้นให้ประธานวุฒิสภาเป็นประธานตุลาการรัฐธรรมนูญ

มาตรา ๒๐๑ ตุลาการรัฐธรรมนูญซึ่งวุฒิสภาและสภาผู้แทนราษฎรแต่งตั้งจะเป็นสมาชิกวุฒิสภา สมาชิกสภาผู้แทนราษฎร สมาชิกสภาท้องถิ่น ผู้บริหารท้องถิ่น ข้าราชการซึ่งมีตำแหน่งหรือเงินเดือนประจำพนักงานรัฐวิสาหกิจ หรือพนักงานส่วนท้องถิ่นมิได้

มาตรา ๒๐๒ ตุลาการรัฐธรรมนูญซึ่งวุฒิสภาหรือสภาผู้แทนราษฎรแต่งตั้งมีวาระการดำรงตำแหน่งสี่ปี แต่อาจได้รับการแต่งตั้งใหม่ได้

ตุลาการรัฐธรรมนูญซึ่งพ้นจากตำแหน่งตามวาระต้องปฏิบัติหน้าที่ไปจนกว่าจะมีการแต่งตั้งตุลาการรัฐธรรมนูญใหม่
