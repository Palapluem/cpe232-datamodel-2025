เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘
หน้า ๖๘

มาตรา ๕ สมาชิกวุฒิสภาหรือสมาชิกสภาผู้แทนราษฎรซึ่งได้รับสัมปทานจากรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจ หรือเป็นคู่สัญญากับรัฐหรือหน่วยราชการหรือหน่วยงานของรัฐหรือรัฐวิสาหกิจ อันมีลักษณะผูกขาดตัดตอน ทั้งนี้ ไม่ว่าโดยทางตรงหรือทางอ้อม ถ้าได้รับสัมปทานหรือเป็นคู่สัญญาอยู่ในวันประกาศใช้รัฐธรรมนูญนี้ ให้คงถือไว้ซึ่งสัมปทานหรือเป็นคู่สัญญานั้นได้ต่อไปจนกว่าจะครบอายุสัมปทาน หรือครบอายุสัญญาหรือจนกว่าสมาชิกภาพจะได้สิ้นสุดลง

มาตรา ๖ ให้สมาชิกสภาผู้แทนราษฎรซึ่งดำรงตำแหน่งอยู่ในวันประกาศใช้รัฐธรรมนูญนี้ คงเป็นสมาชิกสภาผู้แทนราษฎรตามบทบัญญัติของรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔ ซึ่งแก้ไขเพิ่มเติมโดยรัฐธรรมนูญนี้

บทบัญญัติมาตรา ๑๐๕ มาตรา ๑๐๖ และมาตรา ๑๐๙ (๒) ให้ใช้บังคับกับการเลือกตั้งทั่วไปครั้งแรกที่จะพึงมีขึ้นภายหลังวันประกาศใช้รัฐธรรมนูญนี้

การเลือกตั้งสมาชิกสภาผู้แทนราษฎรเพื่อแทนตำแหน่งที่ว่างก่อนการเลือกตั้งทั่วไปครั้งแรกตามวรรคสอง ให้ดำเนินการตามบทบัญญัติของรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔

มาตรา ๗ ในระหว่างที่ยังมิได้มีการแก้ไขเพิ่มเติมบทบัญญัติแห่งกฎหมาย หรือบัญญัติกฎหมายขึ้นใหม่เพื่อให้มีคณะกรรมการการเลือกตั้ง มิให้นำบทบัญญัติมาตรา ๑๑๕ วรรคสองและวรรคสาม ตามบทบัญญัติของรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔ ซึ่งแก้ไขเพิ่มเติม
