หน้า ๔๒
เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

(๑) ถ้าเห็นชอบด้วยกับสภาผู้แทนราษฎร ให้ดำเนินการต่อไปตามมาตรา ๙๓
(๒) ถ้าไม่เห็นชอบด้วยกับสภาผู้แทนราษฎร ให้ยับยั้งร่างพระราชบัญญัตินั้นไว้ก่อน และส่งร่างพระราชบัญญัตินั้นคืนไปยังสภาผู้แทนราษฎร
(๓) ถ้าแก้ไขเพิ่มเติม ให้ส่งร่างพระราชบัญญัติตามที่แก้ไขเพิ่มเติมนั้นไปยังสภาผู้แทนราษฎร ถ้าสภาผู้แทนราษฎรเห็นว่า มิได้เป็นการแก้ไขเพิ่มเติมในสาระสำคัญและเห็นชอบด้วยกับการแก้ไขเพิ่มเติม ให้ดำเนินการต่อไปตามมาตรา ๙๓ ถ้าเป็นกรณีอื่นให้แต่ละสภาตั้งบุคคลที่เป็นหรือมิได้เป็นสมาชิกแห่งสภานั้น ๆ มีจำนวนเท่ากันตามที่สภาผู้แทนราษฎรกำหนด ประกอบเป็นคณะกรรมาธิการร่วมกัน เพื่อพิจารณาร่างพระราชบัญญัตินั้น และให้คณะกรรมาธิการร่วมกันรายงานและเสนอร่างพระราชบัญญัติที่คณะกรรมาธิการร่วมกันได้พิจารณาแล้วต่อสภาทั้งสอง ถ้าสภาทั้งสองต่างเห็นชอบด้วยร่างพระราชบัญญัติที่คณะกรรมาธิการร่วมกันได้พิจารณาแล้ว ให้ดำเนินการต่อไปตามมาตรา ๙๓ ถ้าสภาใดสภาหนึ่งไม่เห็นชอบด้วย ก็ให้ยับยั้งร่างพระราชบัญญัตินั้นไว้ก่อน

คณะกรรมาธิการร่วมกันอาจเรียกเอกสารจากบุคคลใด ๆ หรือเรียกบุคคลใด ๆ มาแถลงข้อเท็จจริง หรือแสดงความคิดเห็นในการพิจารณาร่างพระราชบัญญัติได้และเอกสิทธิ์ที่บัญญัติไว้ในมาตรา ๑๓๑ และมาตรา ๑๓๒ นั้น ให้คุ้มครองถึงบุคคลผู้กระทำหน้าที่ตามมาตรานี้ด้วย

การประชุมคณะกรรมาธิการร่วมกัน ต้องมีกรรมาธิการของสภาทั้งสอง
