เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

บังคับโดยอนุโลม ในกรณีเช่นนี้ พระมหากษัตริย์จะได้ทรงแต่งตั้งผู้นำ ฝ่ายค้านในสภาผู้แทนราษฎรแทนตำแหน่งที่ว่าง

ส่วนที่ ๔
บทที่ใช้แก่สภาทั้งสอง

มาตรา ๑๒๓ สภาชิกวุฒิสภาและสมาชิกสภาผู้แทนราษฎร ย่อมเป็น ผู้แทนปวงชนชาวไทย และต้องปฏิบัติหน้าที่เพื่อประโยชน์ส่วนรวมของ ปวงชนชาวไทย

มาตรา ๑๒๔ ก่อนเข้ารับหน้าที่ สภาชิกวุฒิสภาและสมาชิกสภาผู้แทน ราษฎรต้องปฏิญาณตนในที่ประชุมแห่งสภาที่ตนเป็นสมาชิกด้วยถ้อยคำ ดังต่อไปนี้
"ข้าพเจ้า (ชื่อผู้ปฏิญาณ) ขอปฏิญาณว่า ข้าพเจ้าจะปฏิบัติหน้าที่ ด้วยความซื่อสัตย์ สุจริต เพื่อประโยชน์ส่วนรวมของปวงชนชาวไทย ทั้งจะ รักษาไว้และปฏิบัติตามซึ่งรัฐธรรมนูญแห่งราชอาณาจักรไทยทุกประการ"

มาตรา ๑๒๕ วุฒิสภาและสภาผู้แทนราษฎรแต่ละสภา มีประธาน สภาคนหนึ่งและรองประธานคนหนึ่งหรือสองคน ซึ่งพระมหากษัตริย์ทรง แต่งตั้งจากสมาชิกแห่งสภานั้น ๆ ตามมติของสภา

มาตรา ๑๒๖ ประธานและรองประธานวุฒิสภาดำรงตำแหน่งจนถึง วันก่อนวันเลือกประธานและรองประธานวุฒิสภาใหม่ ซึ่งจะต้องกระทำ ทุกสองปี
