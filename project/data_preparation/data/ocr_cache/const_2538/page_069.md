เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

โดยรัฐธรรมนูญนี้มาใช้บังคับ ซึ่งต้องไม่เกินสองปีนับแต่วันประกาศใช้ รัฐธรรมนูญนี้

มาตรา ๘ ให้ผู้นำฝ่ายค้านในสภาผู้แทนราษฎรซึ่งดำรงตำแหน่ง อยู่ในวันประกาศใช้รัฐธรรมนูญนี้ คงเป็นผู้นำฝ่ายค้านในสภาผู้แทนราษฎร ตามบทบัญญัติของรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔ ซึ่งแก้ไขเพิ่มเติมโดยรัฐธรรมนูญนี้

มาตรา ๙ ให้ประธานวุฒิสภาและรองประธานวุฒิสภาซึ่งดำรง ตำแหน่งอยู่ในวันประกาศใช้รัฐธรรมนูญนี้ คงเป็นประธานวุฒิสภาและ รองประธานวุฒิสภาจนกว่าอายุของวุฒิสภาตามมาตรา ๔ แห่งรัฐธรรมนูญ นี้จะสิ้นสุดลง หรือพ้นจากตำแหน่งก่อนถึงวาระตามมาตรา ๑๒๖ ของ รัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔ ซึ่งแก้ไขเพิ่มเติม โดยรัฐธรรมนูญนี้

ให้ประธานสภาผู้แทนราษฎรและรองประธานสภาผู้แทนราษฎรซึ่ง ดำรงตำแหน่งอยู่ในวันประกาศใช้รัฐธรรมนูญนี้ คงเป็นประธานสภาผู้แทน ราษฎรและรองประธานสภาผู้แทนราษฎรตามบทบัญญัติของรัฐธรรมนูญ แห่งราชอาณาจักรไทย พุทธศักราช ๒๕๓๔ ซึ่งแก้ไขเพิ่มเติมโดยรัฐธรรมนูญนี้
