หน้า ๕๐
เล่ม ๑๑๒ ตอนที่ ๗ ก ราชกิจจานุเบกษา ๑๐ กุมภาพันธ์ ๒๕๓๘

(๙) การพิจารณาเสนอแนะบุคคลเพื่อพระมหากษัตริย์ ทรงแต่งตั้งเป็นผู้ตรวจการรัฐสภาตามมาตรา ๑๖๒ ทวิ
(๑๐) การแถลงนโยบายตามมาตรา ๑๖๙
(๑๑) การเปิดอภิปรายทั่วไปตามมาตรา ๑๗๑
(๑๒) การให้ความเห็นชอบในการประกาศสงคราม ตามมาตรา ๑๘๐
(๑๓) การให้ความเห็นชอบหนังสือสัญญาตามมาตรา ๑๘๑
(๑๔) การแก้ไขเพิ่มเติมรัฐธรรมนูญตามมาตรา ๒๑๑ มาตรา ๑๖๑ ในการประชุมร่วมกันของรัฐสภา ให้ใช้ข้อบังคับ การประชุมของรัฐสภา ในระหว่างที่ยังไม่มีข้อบังคับการประชุมของรัฐสภา ให้ใช้ข้อบังคับการประชุมของสภาผู้แทนราษฎรโดยอนุโลมไปพลางก่อน
มาตรา ๑๖๒ ในการประชุมร่วมกันของรัฐสภา ให้นำบทที่ใช้แก่สภา ทั้งสองมาใช้บังคับโดยอนุโลม เว้นแต่ในเรื่องการตั้งคณะกรรมาธิการ กรรมาธิการที่ตั้งจากผู้ที่เป็นสมาชิกของแต่ละสภาจะต้องมีจำนวนตามหรือ ใกล้เคียงกับอัตราส่วนของจำนวนสมาชิกของแต่ละสภา
มาตรา ๑๖๒ ทวิ พระมหากษัตริย์ทรงแต่งตั้งผู้ตรวจการรัฐสภา มีจำนวนไม่เกินห้าคนตามมติของรัฐสภา และให้ประธานรัฐสภาเป็นผู้ลง นามรับสนองพระบรมราชโองการแต่งตั้งผู้ตรวจการรัฐสภา
คุณสมบัติ หลักเกณฑ์ วิธีการแต่งตั้ง การถอดถอน และอำนาจ หน้าที่ให้เป็นไปตามที่กฎหมายบัญญัติ
