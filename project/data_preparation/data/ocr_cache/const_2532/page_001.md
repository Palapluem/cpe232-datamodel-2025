ภูมิพลอดุลยเดช ป.ร.
ให้ไว้ ณ วันที่ ๒๔ สิงหาคม พ.ศ. ๒๕๓๒
เป็นปีที่ ๔๔ ในรัชกาลปัจจุบัน

พระบาทสมเด็จพระปรมินทรมหาภูมิพลอดุลยเดช มีพระบรมราชโองการโปรดเกล้า ฯ ให้ประกาศว่า

โดยที่เป็นการสมควรแก้ไขเพิ่มเติมรัฐธรรมนูญแห่งราชอาณาจักรไทย

จึงทรงพระกรุณาโปรดเกล้าฯ ให้ตรารัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไขเพิ่มเติมขึ้นไว้ ดังต่อไปนี้

มาตรา ๑ รัฐธรรมนูญนี้เรียกว่า “รัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไขเพิ่มเติม (ฉบับที่ ๒) พุทธศักราช ๒๕๓๒”
