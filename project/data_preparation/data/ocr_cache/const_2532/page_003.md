ฉบับพิเศษ หน้า ๓ เล่ม ๑๐๖ ตอนที่ ๑๔๒ ราชกิจจานุเบกษา ๓๐ สิงหาคม ๒๕๓๒

หมายเหตุ :- เหตุผลในการประกาศใช้รัฐธรรมนูญแห่งราชอาณาจักรไทย แก้ไข เพิ่มเติมฉบับนี้ คือ เนื่องจากรัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๒๑ ได้บัญญัติให้ประธานวุฒิสภาเป็นประธานรัฐสภา ให้ประธานสภาผู้แทนราษฎรเป็นรองประธานรัฐสภา และให้นำข้อบังคับการประชุมของวุฒิสภามาใช้บังคับในการประชุมร่วมกันของรัฐสภาโดยอนุโลม บัดนี้ การปกครองระบอบประชาธิปไตยภายใต้รัฐธรรมนูญได้ก้าวหน้ามาเป็นลำดับ สมควรแก้ไขเพิ่มเติม รัฐธรรมนูญดังกล่าวเพื่อให้ประธานสภาผู้แทนราษฎรเป็นประธานรัฐสภา ให้ประธานวุฒิสภาเป็นรองประธานรัฐสภา และให้นำข้อบังคับการประชุมของสภาผู้แทนราษฎรมาใช้บังคับในการประชุมร่วมกันของรัฐสภา ทั้งนี้ เพื่อให้สอดคล้องกับเจตนารมณ์และหลักการปกครองในระบอบประชาธิปไตย จึงจำเป็นต้องแก้ไข รัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช ๒๕๒๑
