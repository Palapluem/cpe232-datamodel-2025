# CPE232 Data Modeling 2025

Course workspace for CPE232 Data Modeling, semester 1/2025. The repository keeps labs, homework, lecture material, quiz preparation, hackathon work, and project files in one portable place.

## Structure

```text
cpe232-datamodel-2025/
├── hackathon/   # Hackathon or applied modeling work
├── homeworks/   # Homework submissions and supporting files
├── labs/        # Lab exercises
├── lectures/    # Course lecture material
├── project/     # Main project work
├── quiz/        # Quiz preparation
├── .gitignore
└── README.md
```

## How To Use On Another Machine

1. Clone the repository.
2. Open the relevant folder for the assignment or project.
3. Install only the tools required by that folder, such as Python, SQL tooling, spreadsheet software, or diagramming tools.
4. Keep generated files, caches, and local exports out of Git unless they are part of a final submission.

## Repository Policy

- Track source files, notebooks, reports, diagrams, and final assignment artifacts.
- Do not track local assistant config, virtual environments, caches, or machine-specific IDE settings.
- If a dataset is too large or private, document where it should be restored instead of committing it.
